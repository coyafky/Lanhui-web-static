## 一、优化逻辑说明

**电动踏板 ≠ 轮毂页**：

| 维度 | 轮毂页（产品导向） | 电动踏板页（车型覆盖导向） |
|---|---|---|
| 客户决策路径 | "我有什么款式可以选" | **"我的车能不能装"** |
| 核心卖点 | 工艺/尺寸/颜色/参数 | **品牌覆盖广 + 适配车型多 + 3 款式可选** |
| 筛选维度 | 工艺→尺寸→PCD/ET→颜色 | **品牌→车型→适配年份→取信号方式** |
| 页面重心 | 产品图库+参数筛选 | **品牌墙 + 车型适配查询 + 款式对比** |

**电动踏板的购买逻辑**：
1. 客户先确认"我的车型在不在适配列表" → 如果在，继续看款式
2. 客户关心"取信号方式是否匹配" → 对插/线夹/原厂对插/接线
3. 客户关心"选哪款" → 无灯/单流光/大灯带 三选一

**⚠️ 供应商保密**：供应商"百粤"属于内部信息，前端**绝不展示**。产品仅以"蓝辉轻改电动踏板"品牌呈现。

## 六、款式适配逻辑

### 6.1 取信号方式 → 款式推荐

| 取信号方式 | 推荐款式 | 说明 |
|---|---|---|
| 对插 | 全部三款均可 | 安装最简便，三款都合适 |
| 原厂对插 | 全部三款均可 | 安装较简便 |
| 线夹 | 无灯款 / 单流光 | 需确认门板走线空间 |
| 接线 | 无灯款优先 | 结构最简单，故障点最少 |

### 6.2 车型类型 → 款式推荐

| 车型类型 | 推荐款式 | 说明 |
|---|---|---|
| 家用 SUV（比亚迪汉/唐） | 无灯款 / 单流光 | 务实为主 |
| 大型 SUV / 商务（理想 L9/蔚来 ES8） | 单流光 / 大灯带 | 氛围需求高 |
| MPV（腾势 D9/别克 GL8） | 单流光 / 大灯带 | 商务接待场景 |
| 皮卡 / 硬派越野 | 无灯款 | 实用优先 |
