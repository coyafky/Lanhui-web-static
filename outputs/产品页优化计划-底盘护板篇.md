## 一、优化逻辑说明

**底盘护板 ≠ 轮毂页**：

| 维度 | 轮毂页（产品导向） | 底盘护板页（车型覆盖导向） |
|---|---|---|
| 客户决策路径 | "我有什么款式可以选" | **"我的车能不能装"** |
| 核心卖点 | 工艺/尺寸/颜色/参数 | **品牌覆盖广 + 车型覆盖多** |
| 筛选维度 | 工艺→尺寸→PCD/ET→颜色 | **品牌→车型→年款→动力类型** |
| 页面重心 | 产品图库+参数筛选 | **品牌墙 + 车型搜索 + 适配详情** |

**底盘护板的购买逻辑**：
1. 客户先确认"我的车型在不在支持列表" → 如果在，继续看方案
2. 客户关心"有几个方案可选" → 多供应商覆盖 = 更多选择
3. 客户关心"装了什么/怎么装" → 五段分区 + 材料 + 防护部位

## 三、官网现状

### 3.1 现有页面结构

```

├── ChassisHero —— 产品介绍（五段式底盘防护）
```

## 五、数据导入策略

### 5.1 数据源

| 数据 | 位置 | 格式 | 数量 |
|---|---|---|---|
| 品牌数据 | `json/brands/` | JSON | 121 |
| 车型数据 | `json/models/` | JSON | 1534 |
| 产品图 | `json/products/` | JSON | 2 |
| 产品图文件 | `image/` | PNG | 2 |

### 5.2 数据转换

```
json/brands/*.json (121) + json/models/*.json (1534)
→ 解析聚合
→ src/lib/chassis-brands.ts（品牌列表 + 车型列表 + 适配详情）
```

**关键处理**：
1. 品牌名从 `car_brand` 字段提取
2. 车型名从 `car_model` 字段提取
3. `supplier_coverage` 数组仅用于内部统计，**不传入前端**
4. 方案详情从 `schemes` 数组提取，但**剔除 `supplier` 字段**
5. 搜索索引：品牌名 + 车型名 → 全文搜索
6. ⚠️ 数据传递给前端前必须过滤掉所有供应商相关信息

### 5.3 数据模型

```typescript
export interface ChassisBrand {
  name: string;              // "比亚迪"
  modelCount: number;        // 42
  hasMultipleSchemes: boolean; // 是否有多个方案可选（不暴露供应商数量）
  models: ChassisModelSummary[];
}

export interface ChassisModelSummary {
  name: string;              // "汉EV"
  schemeCount: number;       // 5
}

export interface ChassisModelDetail {
  brand: string;             // "比亚迪"
  model: string;             // "汉EV"
  schemeCount: number;       // 方案总数
  schemes: ChassisScheme[];
}

export interface ChassisScheme {
  schemeId: string;          // "scheme_1"（不展示）
  // ⚠️ supplier 字段仅内部使用，绝不传入前端组件
  supplier?: string;         // 内部："宝凡汽车底护板"（不展示）
  applicableYear: string;    // "2020-2024"
  powerType: string;         // "纯电"
  applicableVersion: string; // "创世版/荣耀版"
  displacementOrRange: string; // "506-715km"
  material: string;          // "铝镁合金"
  protectionZones: string[]; // ["前电机", "电池前段", "电池后段", "后电机"]
  importantNotes?: string;   // "需确认电池包版本"
}
```

> ⚠️ **供应商保密原则**：
> - `supplier` 字段仅在内部数据中存在，前端组件**绝不渲染**供应商名称
> - 品牌墙不展示"供应商覆盖"数量，仅展示"多方案可选"
> - 适配详情仅以"方案 1/2/3"编号，不标注供应商名称
