# 文案合规审查

## 何时使用

- 新增 / 修改任何面向客户的文案
- 新增产品页、车型页、参数表
- 上线前的内容检查

**对应规则**：`rules/content-copy.md` · **决策依据**：`adr/0005-copy-legal-constraints.md`

## 检查步骤

### 1. 极限词扫描

对目标文案逐句检查是否含以下词（含变体）：

```
最 / 最佳 / 最强 / 最先 / 最好 / 最新（修饰品质时）
第一 / 唯一 / 唯一指定
顶级 / 顶尖 / 极品
旗舰（修饰品质时） / 独创 / 首创
进口同款 / 原厂同款
国家级 / 全球领先 / 行业领先 / 遥遥领先
```

### 2. 免责声明检查

| 位置 | 必须有 |
|---|---|
| 参数页（技术参数表） | 「实际以门店实测为准」类声明 |
| 产品展示页 | **不得出现价格** |
| 效果描述 | 不得承诺具体效果 |

### 3. 输出报告

按以下格式输出，发现问题时**必须给出具体位置与修改建议**：

```
合规检查：<文件/页面>
- 极限词：N 处
  - 位置 · 原文 → 建议改为
- 免责声明：✅ / ❌ 缺失位置
- 价格：✅ 无 / ❌ 位置
```

## 自动化

用脚本批量扫描（推荐先跑它，再人工复核）：

```bash
python3 skills/content-copy-audit/scan.py <路径或文件...>
```

脚本退出码：`0` 通过 / `1` 发现问题。
