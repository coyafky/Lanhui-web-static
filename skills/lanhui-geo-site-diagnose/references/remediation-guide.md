# 蓝辉官网 GEO 修复指引

> 依据 2026-08-31 诊断的 remediation-backlog，按优先级给出蓝辉具体的落地动作。所有建议遵循证据纪律，不夸大效果。

## 1. P60｜证据与引用就绪（evidence_citation）— 首页 83，品牌/代理页 50
**目标**：让 AI 在引用蓝辉产品主张时有可引用的数据来源。
- 在改色膜/车衣/轮毂的**关键参数主张**旁注明来源：透光率、厚度(mil)、耐刮擦等级、质保年限、实测数据。
- 落地形态：产品详情页加「技术参数表 + 数据来源说明」区块；FAQ 加「依据」脚注。
- 每个参数给原始出处（第三方检测报告、厂商规格、店内实测），单页 ≥2 处可摘录引文。

## 2. P45｜权威与信任（authority_trust）— 全站 50（最集中短板）
**目标**：建立「作者/机构可追责」信号。
- 全站加**署名主体**：文章/博客加「作者 + 审核人 + 机构」（如「蓝辉轻改技术中心」）。
- 品牌页(brand)声明经营主体、成立时间、门店/服务凭证。
- 联系页(contact)补可核验信任锚点（统一社会信用代码、经营资质、线下门店可核验信息）。
- 每个权威性页面向已知可追责主体（人或机构）。

## 3. P30｜内容架构对齐（architecture_coverage）— 代理页 68
**目标**：URL、title、H1 与页面主任务一致。
- 代理页(agent)：检查 URL/TITLE/H1 是否都围绕「服务范围/城市代理/加盟」单一主任务，收敛发散词。
- 品牌页(85)/产品页(92) 做同款自查。

## 4. P30｜新鲜度（freshness）— 品牌/产品页 50
**目标**：sitemap lastmod 真实可解释。
- 让 lastmod 反映内容真实变更时间（Next.js 静态导出可驱动）；不更新时不伪造新时间。
- 博客/blog 若持续抓取超时，先修可达性（HTTP 模式稳过）再谈新鲜度。

## 优先级排序
1. 先补**署名主题 + 证据来源注解**（P60/P45，影响面最大，直接提 authority + evidence 两项）。
2. 再对齐**页面主任务**与 **lastmod**（P30，成本低）。
3. `/blog` 抓取超时单独优先处理——它一旦被正常抓取，覆盖维度会明显提升。

## 复检方式
修完跑一次本 SKILL 全站诊断（overall 应从 85 起步），对比 authority_trust 与 evidence_citation 两维度是否从 50-83 上行。
