# 博客列表（品牌资讯）

## 一、页面定位

> 一句话：品牌资讯列表页承担「内容获客 + SEO/GEO 长尾覆盖」，用选膜干货、轻改科普与门店动态把搜索流量引向到店。

## 八、技术实现要点

- **数据来源**：`src/lib/blog.ts`（`getAllArticles` / `getAllCategories` / `paginateArticles` / `getCategorySlug` / `formatArticleDate` / `BLOG_PAGE_SIZE = 9`）；文章源文件 `src/content/articles/*.md`（frontmatter + Markdown 正文）。
- **路由注册**：`src/app/blog/page.tsx`；相关动态/分页路由 `src/app/blog/[slug]`、`src/app/blog/category/[slug]`、`src/app/blog/page/[n]`。
- **组件复用**：`Header` / `Footer` / `ArticleCard` / `CategoryNav` / `Pagination` / `PhoneCta`。
- **排序与过滤**：文章按 `publishedAt` 倒序，过滤 `draft: true`，重复 slug 会构建报错；分类 URL 用英文 slug 以规避静态导出中文动态段编码问题。
- **阅读时长**：按中文约 400 字/分钟估算，最少 1 分钟。
