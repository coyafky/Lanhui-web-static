# 联系我们

## 一、页面定位

> 一句话：联系我们页集中承载「电话、地址、营业时间、导航、服务流程与品牌承诺」，是线上流量落到「到店」的最后一公里页面。

- **目标用户**：已决定到店、正在找电话 / 地址 / 路线的高意向车主。
- **核心诉求**：一键拨号、一键高德导航、看清服务流程与质保承诺。
- **转化目标**：电话咨询 + 高德导航到店（本页两个核心动作）。
- **在导航中的位置**：未进入主导航；主要通过 Header「联系我们」按钮、Footer 联系方式、门店页与落地页链接进入。

## 八、技术实现要点

- **数据来源**：
  - `src/lib/store.ts`（`stores[0]`：门店地址、电话、营业时间、描述、经纬度）
  - `src/lib/brand.ts`（品牌兜底：address / businessHours / currentStore）
  - `src/lib/store-map.ts`（`getAmapNavigationUrl` 生成高德导航链接）
  - `contactData` 常量内联于 page 文件（热线占位、服务流程、品牌承诺）
- **路由注册**：`src/app/contact/page.tsx`。
- **组件复用**：`Header` / `Footer` / `InfoRow`（`src/components/InfoRow`）。
- **注意事项**：电话展示逻辑为「门店电话存在则用 `store.phone`，否则回退 `contactData.hotline.displayNumber`」，因此当前展示真实号码 18825425068；`contactData.hotline.number` 的 `400-XXX-XXXX` 为未启用占位。
