# 品牌历程

## 一、页面定位

> 一句话：品牌历程用时间线讲清「蓝辉轻改从 2026 年成立到顺德大良店开放」的关键节点，为客户提供「品牌真实、在持续发展」的时间证据。

- **目标用户**：已经在了解品牌的潜在车主、合作方；关注品牌成长轨迹的用户。
- **核心诉求**：确认品牌不是「空壳」，有真实的成立时间、门店落地与产品发布节点。
- **转化目标**：强化信任，承接品牌介绍页，向下引导至门店服务与产品中心。
- **在导航中的位置**：`/brand` 二级页；主导航「品牌介绍」下拉第二项「品牌历程」；页内面包屑「品牌介绍 › 品牌历程」。

## 八、技术实现要点

- **数据来源**：`src/lib/history.ts`（`milestones` 数组，字段：year / month? / title / description / highlight?）。
- **路由注册**：`src/app/brand/history/page.tsx`。
- **组件复用**：`Header` / `Footer` 共享；`MilestoneCard` 与 `TimelineDot` 定义在本 page 文件内。
- **响应式布局**：桌面（`md:` 及以上）为左右交替时间线（`isLeft = i % 2 === 0`），移动端为左侧单轴 + 卡片。
- **注意事项**：数据注释明确提示「不要捏造具体日期、签约方、媒体等未经证实的细节」，新增节点请遵循该纪律。
