# 产品中心

## 一、页面定位

> 一句话：产品中心是整站的「流量分拣中心」，提供两条找方案路径——「按车型找」与「按项目看」，把车主导向具体品牌车型页或服务品类页。

- **目标用户**：已明确想改些什么、或想看「我这个车型能改什么」的新能源车主。
- **核心诉求**：快速定位到「我的车型方案」或「我想做的项目」。
- **转化目标**：点击进入品牌车型页 / 服务品类页，最终导向到店沟通与施工。
- **在导航中的位置**：主导航第 2 项「产品中心」（含服务分类 + 品牌车型两级下拉）；Footer「产品中心」列；首页多处入口。

## 八、技术实现要点

- **数据来源**：`src/lib/product-routes.ts`（`ALL_SERVICES` / `getLiveBrands` / `getLiveServices` / `ALL_BRANDS` / `ALL_MODELS`）、`src/lib/products.ts`（窗膜套餐、`carTvImages` 等）、`src/lib/product-breadcrumbs.ts`、`src/lib/json-ld.ts`。
- **路由注册**：`src/app/product/page.tsx`；`src/app/product/layout.tsx` 统一注入 `Header` / `Footer`。
- **组件复用**：`ProductHero`、`MobileProductContent` + `StickyTabBar`、`VehicleTopicMap`、`FilmServiceMap`、`LightModMap`、`BusinessComfortMap`、`PracticalAccessoryMap`、`CarCareServiceMap`、`BrandMatrixMap`、`MaterialSlice`。
- **响应式交互**：`MobileProductContent` 在 `<768px` 显示 Sticky Tab（`按车型 / 按项目`），桌面端平铺全部区块；`VehicleTopicMap` / `BrandMatrixMap` 用 `useState` 管理 hover。
- **服务分组逻辑**：页面按 `ServiceGroup`（film / light_mod / business_comfort / practical_accessory / car_care）分组渲染，仅取 `status: live` 的服务。
