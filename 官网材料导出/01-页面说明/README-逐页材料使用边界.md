# 逐页材料使用边界

本目录的逐页说明形成于较早的网站版本，未覆盖 2026-10-24 当前本地源码的全部 48 个品牌系列、70 个车型和新增服务页。页面区块、图片路径、项目数和文案可能已变化，**不可直接当作当前页面验收结论**。

使用顺序：

1. 先看 `../00-网站架构与说明/03-页面清单与路由地图.md`，确认当前路径与页面入口。
2. 再看对应 `src/app/**/page.tsx` 的 import，定位现行数据与组件。
3. 对照本地预览和业务原始资料；图片另查 `public/images/` 与引用路径。
4. 只有经当前页面验证的内容才更新本目录；未覆盖的新页按同样方法补充。

本目录保留旧资料用于追溯，不表示旧内容已经上线或仍然适用。
