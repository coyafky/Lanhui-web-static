# 特斯拉（品牌系列页）

## 一、页面定位

> 一句话：Tesla 车膜保护与日常用车升级服务入口，用「场景 → 基础服务 → 流程 → FAQ」把纯视觉智驾车型的施工避让与电气质保边界讲清楚，引导车主发车型咨询。

- **目标用户**：Tesla Model 3 / Model Y（含 Model S、Model X、Model Y L）车主，尤其新提车、日晒通勤、在意辅助驾驶完整性的用户。
- **核心诉求**：车膜怎么选、贴膜怎样避开摄像头、轮毂与脚垫能不能通用、电气项目会不会影响质保、本地哪里能施工。
- **转化目标**：微信咨询（打开微信弹窗）→ 发来车型/年款确认方案 → 到店施工。
- **在导航中的位置**：顶部导航「产品中心」→ 特斯拉（品牌一级入口）。Tesla 无车型子页面（`modelSlugs: []`）。

A 看用车环境：长期户外停放、日晒通勤明显的先做隔热膜，改善夏季车内温度；高频通勤、在意漆面保值的先做车衣。两者施工互不冲突，可以同期安排；先确认版本和玻璃配置，再定膜料和施工顺序。
Q 特斯拉贴膜怎样避开前挡和车身摄像头区域？
A 特斯拉依赖摄像头实现辅助驾驶，官方要求摄像头保持清洁且无遮挡。施工前会记录前挡、翼子板、B 柱和尾部摄像头的位置与感知窗口，车衣、改色膜裁切精确避让，前挡隔热膜避开摄像头识别区；完工后逐项检查摄像头提示与辅助驾驶功能。
Q Model 3、Model Y 的脚垫和轮毂可以通用吗？
A 不能通用。两者在轴距、地台形状、前后备厢结构和轮毂数据上差异明显：脚垫需要按车型分体裁形；轮毂的尺寸、ET 值和承载等级要分别核对。发来车型和年款，先确认适配清单再谈款式。
Q 安装电动门把手、仪表或电动前备厢是否需要改线？
A 视项目而定：部分项目走原车接口对插、可恢复原状；部分需要接取低压电源。我们会在施工前书面告知接线方式、可恢复性和质保边界，留存施工记录；OTA 升级后如出现相关提示，可回店复检。介意质保风险的车主建议只做不改线项目。
Q 佛山顺德大良哪里可以做特斯拉贴膜和洗美养护？
A 蓝辉轻改门店位于佛山顺德大良，提供特斯拉车膜、轮毂、脚垫和洗美养护等服务，支持到店咨询和预约施工。发来车型、年款和需求，先确认方案与工期再安排到店。
