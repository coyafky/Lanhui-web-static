# 问界（品牌系列页）

## 一、页面定位

> 一句话：问界（鸿蒙智行）全系日常保护与舒适升级入口，先讲「6 类基础服务」，再按 M6 / M7 / M8 三个车型分流到子页，覆盖踏板、地板等家庭高频需求。

- **目标用户**：问界 M6、M7、M8 车主，尤其城市通勤家用、6 座家庭、商务与高端家庭用户。
- **核心诉求**：新车先做哪些项目、家庭上下车与后排好收拾、踏板/地板/轮毂怎么按车型确认、是否影响质保。
- **转化目标**：微信咨询（提交车型年款配置）→ 到店评估 → 施工；或进入 M6/M7/M8 子页。
- **在导航中的位置**：顶部导航「产品中心 → 问界」，下挂车型「M6 / M7 / M8」。

[眉标] 常见问题
[H2] 问界车主最常问的问题
Q 是否所有问界车型都能安装？
A 不同年款和配置在传感器、线束、座椅和滑轨结构上存在差异。发来行驶证车型、年款、配置和相关部位照片，可以先做线上初步确认，再决定是否到店。
Q 新车最推荐先做哪些项目？
A 优先解决高频磨损和暴晒：车衣或隔热膜、专车脚垫、基础洗美。其余项目建议用一段时间后按实际需求再加，不需要的不建议做。
Q 家庭用户最常关注哪些项目？
A 电动踏板（老人儿童上下车）、地板总成（后排好收拾）、专车脚垫和内饰清洁。涉及座椅和滑轨结构的项目需要按车型确认。
Q 可以只做单个项目吗？
A 可以。页面组合只是选择参考，最终按你的车型和实际需求确定，不捆绑销售。
Q 会影响原车质保吗？
A 施工前会明确告知项目是否涉及拆装、打孔、线路或结构改动，以及可能的影响范围；你确认后才施工。最终以具体项目和车辆情况为准。
Q 工期大概多久？
A 车膜类通常 1–3 天；踏板、地板等安装类通常半天到 1 天；洗美养护 2–4 小时。具体受车型结构和项目组合影响，确认方案时同步告知。
Q 报价受什么影响？
A 主要是车型尺寸、材料版本和项目组合。先确认车型与方案再给报价，不在确认前给模糊区间。
Q 售后包含什么？
