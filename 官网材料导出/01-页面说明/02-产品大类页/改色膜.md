# 改色膜

## 一、页面定位

> 一句话：用「先选风格、再选颜色、最多并排对比 3 款」的交互帮车主快速锁定改色方向，再用施工保障、验收标准与养护规则建立「贴得好」的信任，最终引导到店看色板与微信咨询。

- **目标用户**：追求个性外观的车主、年轻车主、新能源车主（`products.ts` `color-film.audience`）。
- **核心诉求**：不动原车漆改变车身颜色；挑到合适的色系与质感；担心色差、包边、撕除伤漆。
- **转化目标**：微信咨询（企业微信弹窗）→ 到店看实物色板、确认漆面状态 → 排期施工。
- **在导航中的位置**：顶部导航「产品中心」下拉 → 服务分类「改色膜」（`navLabel: 改色膜`，P0，film 组）。

### 5. 施工保障（`<ColorFilmConstructionProofs />`）

- **小标题**：施工保障
- **H2**：好膜，也要贴得好
- **导语**：改色膜最终效果取决于施工质量。从漆面检测到交付复检，每一步都不能省。
- **4 项证据**：漆面施工前检测 / 实物色板确认 / 专车包边方案 / 交付复检（文案见附录）
- **重要说明（H4）**：关于撕除与漆面影响的重要说明 —— 改色膜撕除时对原车漆面的影响取决于漆面原始状态。原厂漆面在正常施工和标准操作下撕除，通常不会损伤漆面；补漆、老化漆面或已有损伤的漆面，撕除时可能存在局部脱漆风险。我们会在施工前检测漆面状态并与你确认，不建议在已知漆面问题区域直接覆膜。质保范围以施工前双方确认的检测记录为准。

### 6. 验收标准 + 质保与养护（`<ColorFilmWarranty />`，数据来自 `serviceGuarantee`）

- **小标题**：质保与养护
- **H2**：验收有标准，养护有方法
- **导语**：施工前明确验收标准，交付后告知养护要点。你对膜面的每一条疑问，都应该有明确答案。
- **H3 验收标准**（表：项目 / 标准）→ 折痕、划痕、起泡 → 不允许出现；尘点 → 单个面少于 6 个尘点，且以边缘为标准；胶痕 → 平面不能出现；曲面边角处不大于 3mm；包边 → 包边处拒绝漏边、漏角。
- **H3 施工后养护（4 条）**：三天内不要高速行驶；雷达异常及时回店；改色膜三天回店复检；三天内不能洗车（原文见附录）。
- **H3 日常养护提示（6 条）**：鸟粪/胶水/树脂/泡沫、空调滴水/地下车库滴水、油烟排风扇附近、婚车吸盘、易褪色物品、膜面护理。

### 7. 服务流程（`<ColorFilmProcess />`，含预估时长）

- **小标题**：服务流程
- **H2**：从到店到交付，每一步都清晰
- **导语**：到店交付，统一规范。施工时长取决于车型与面积，具体以到店评估为准。
1. 01 到店沟通（约 20 分钟）：到蓝辉轻改顺德大良店，面对面沟通用车场景与改色偏好。
2. 02 漆面检测 + 色板确认（约 30 分钟）：检测原车漆面状态，在日光和室内光线下确认色板质感与颜色。
3. 03 方案推荐 + 排期（约 15 分钟）：结合车型、预算与风格偏好，推荐适合的改色方案并安排施工时间。
4. 04 施工交付 + 复检（1-3 天，视车型与面积）：专车专用电脑裁膜 + 手工包边收口，交付前逐项复检并提示养护要点。

## 八、技术实现要点

- 数据来源：基础系列字段在 `src/lib/products.ts`（`color-film.colorSeries` / `hotColors`）；页面实际渲染使用 `src/lib/color-film-data.ts` 的富数据（`colorFilmSeriesRich` / `STYLE_GROUPS` / `HOT_COLOR_CASES` / `TEXTURE_FILTERS` / `COLOR_FAMILY_FILTERS`）。
- 路由注册：`product-routes.ts` SERVICES `color-film`（film 组，P0，live）。
- 组件复用：全部为 `src/components/color-film/` 专属组件；`serviceGuarantee`（验收/养护/日常提示）复用于 `ColorFilmWarranty`。
- 面包屑：`getProductBreadcrumbs("/product/color-film")` → 首页 / 产品中心 / 改色膜。
- 注意事项：
  - 本页**不使用**通用 `ProductDetail.tsx`，故 `products.ts` 的 `colorSeries`/`hotColors` 字段未直接渲染，两者存在数据冗余/口径需对齐的风险。
  - Hero 位于 `<main>` 之外（`ColorFilmHero` 在 `<main>` 之前）。
  - 颜色图库/风格筛选为客户端交互（`ColorFilmPageClient`，"use client"）。
  - 本页无 Product 结构化数据。

漆面施工前检测：施工前全面检测原车漆面状态。原厂漆、补漆、老化漆面的附着力和施工方案不同，我们会根据检测结果选择适合的处理方式。
实物色板确认：到店后先看真实色板，在不同光线下确认颜色质感。屏幕显示与实际膜面色差不可避免，实物确认是选色的最后一道保障。
专车包边方案：每款车型的门边、翼子板、保险杠弧度不同，我们使用专车数据裁膜并手工包边收口，确保边缘服帖不留白边。
交付复检：施工完成后逐块检查包边、气泡、色差和边角贴合度，发现问题当场修正。交付前确保每个角度都经得起细看。
关于撕除与漆面影响的重要说明：改色膜撕除时对原车漆面的影响取决于漆面原始状态。原厂漆面在正常施工和标准操作下撕除，通常不会损伤漆面；补漆、老化漆面或已有损伤的漆面，撕除时可能存在局部脱漆风险。我们会在施工前检测漆面状态并与你确认，不建议在已知漆面问题区域直接覆膜。质保范围以施工前双方确认的检测记录为准。

【质保与养护】
质保与养护
验收有标准，养护有方法
施工前明确验收标准，交付后告知养护要点。你对膜面的每一条疑问，都应该有明确答案。
验收标准（项目 / 标准）：
  折痕 → 不允许出现
  划痕 → 不允许出现
  起泡 → 不允许出现
  尘点 → 单个面少于 6 个尘点，且以边缘为标准
  胶痕 → 平面不能出现；曲面边角处不大于 3mm
  包边 → 包边处拒绝漏边、漏角
施工后养护：
  三天内不要高速行驶 — 装贴后 3 天内，时速建议控制在 60 码以内
  雷达异常及时回店 — 如果雷达报警或异响，可回店处理雷达孔位置膜面
  改色膜三天回店复检 — 改色膜施工后 3 天建议回店复检
  三天内不能洗车 — 改色膜施工后 3 天内不建议洗车
日常养护提示：
  鸟粪/胶水/树脂/泡沫 — 酸碱性强的物质不要长时间停留在膜面，应及时清理
  空调滴水/地下车库滴水 — 避免长期停放在含重金属滴水位置下方
  油烟排风扇附近 — 避免停放在油烟排风扇旁，防止油渍附着膜面
  婚车吸盘 — 已贴车衣车辆不建议将吸盘直接吸附在膜面
  易褪色物品 — 不要长时间放置在膜面，避免染色
  膜面护理 — 建议定期进行膜面护理，保持膜面光亮如新
