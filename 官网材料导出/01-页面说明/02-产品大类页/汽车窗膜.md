> 一句话：用「7 套套餐 + 参数解读 + 单品参数表」把窗膜从「看颜色深浅」拉回「隔热/清晰/隐私/信号/稳定」的理性选择，并说明专业施工如何保证性能落地，最终引导到店匹配前挡+侧后挡组合。

### 3. 窗膜核心作用（`<WindowFilmBenefits />`）

- **小标题**：窗膜核心作用
- **H2**：为什么要贴一张好窗膜？
- **导语**：不是单看颜色深浅。合适的窗膜组合，需要同时处理热量、光线、紫外线、隐私与玻璃安全辅助。
- **主卡 1**：H3「隔热，是减少热量进入」— 高效隔热膜层可减少太阳热量进入车内，降低长时间曝晒后的闷热感。子项「空调更快进入舒适区」— 热量输入减少后，空调更容易把车内带回舒适温度。
- **主卡 2**：H3「隐私，是减少车外直视感」— 合理的侧后挡组合可降低车外对车内的直视感，为乘员与随车物品增加一层视觉遮蔽。子项「车内向外仍要清晰」— 隐私不等于一味压暗，仍需兼顾白天、夜间和雨天视野。
- **辅助 3 项**：紫外线阻隔 / 减少眩光干扰 / 玻璃安全辅助（文案见附录）
- **尾注**：实际体验会受膜材参数、玻璃面积、车型结构与施工质量影响，具体以产品规格和实车效果为准。

### 4. 参数解读（`<WindowFilmParameterExplainer />`）

- **小标题**：参数解读
- **H2**：参数怎么选，先看这几个指标
- **导语**：把膜参数翻译成用车体验，重点关注这几个核心指标即可。
- **参数表（参数 / 全称·含义 / 用户理解）**：

| 参数 | 全称 / 含义 | 用户理解 |
|---|---|---|
| 可见光阻隔率 | 当前资料口径下的可见光指标 | 影响视觉明暗和隐私感，前挡应优先保证清晰视线。行业常见的可见光透过率 VLT 含义与此不同，以品牌资料口径为准。 |
| UVR | 紫外线阻隔率 | 关系到防晒、内饰老化、皮肤舒适度。 |
| IRR | 红外线阻隔率 | 关系到体感热量，红外线越高通常越抗晒热。 |
| TSER | 总太阳能阻隔率 | 综合隔热指标，更接近整体隔热表现。 |
| 厚度 | 膜层厚度 | 影响施工手感、安全附着和产品定位，不应单独作为唯一判断标准。 |

【窗膜核心作用】
窗膜核心作用
为什么要贴一张好窗膜？
不是单看颜色深浅。合适的窗膜组合，需要同时处理热量、光线、紫外线、隐私与玻璃安全辅助。
隔热，是减少热量进入：高效隔热膜层可减少太阳热量进入车内，降低长时间曝晒后的闷热感。
  空调更快进入舒适区：热量输入减少后，空调更容易把车内带回舒适温度。
隐私，是减少车外直视感：合理的侧后挡组合可降低车外对车内的直视感，为乘员与随车物品增加一层视觉遮蔽。
  车内向外仍要清晰：隐私不等于一味压暗，仍需兼顾白天、夜间和雨天视野。
紫外线阻隔：减少紫外线进入，帮助保护乘员皮肤并延缓内饰老化。
减少眩光干扰：让强光与逆光更柔和，同时保留观察路况所需的亮度。
玻璃安全辅助：玻璃破损时，膜层可辅助黏附部分碎片，减少飞散风险。
实际体验会受膜材参数、玻璃面积、车型结构与施工质量影响，具体以产品规格和实车效果为准。

【参数解读】
参数解读
参数怎么选，先看这几个指标
把膜参数翻译成用车体验，重点关注这几个核心指标即可。
可见光阻隔率 — 当前资料口径下的可见光指标 — 影响视觉明暗和隐私感，前挡应优先保证清晰视线。行业常见的可见光透过率 VLT 含义与此不同，以品牌资料口径为准。
UVR — 紫外线阻隔率 — 关系到防晒、内饰老化、皮肤舒适度。
IRR — 红外线阻隔率 — 关系到体感热量，红外线越高通常越抗晒热。
TSER — 总太阳能阻隔率 — 综合隔热指标，更接近整体隔热表现。
厚度 — 膜层厚度 — 影响施工手感、安全附着和产品定位，不应单独作为唯一判断标准。

【施工保障】
施工保障
好膜，也要贴得好
从产品核验到施工环境与车辆保护，每一步都围绕膜材性能的稳定呈现。
正品现场核验：品牌、系列、型号，施工前现场核验，确保所贴即所选。不混用、不降级、不以次充好。
无尘空间施工：专用施工空间、降尘处理、玻璃清洁与刮水流程，保障贴合品质。不是路边露天作业。
新能源车型适配：无框车门、大曲面玻璃、复杂门板精细适配，不是通用裁切方案，专车专用更贴合。
内饰遮蔽保护：仪表台、门板、座椅全遮蔽，防止施工液渗入电子件与内饰。贴膜不伤车。
