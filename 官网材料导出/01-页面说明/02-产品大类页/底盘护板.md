# 底盘护板（铝镁合金五段式）

## 一、页面定位

> 一句话：用「五段分区结构 + 安装适配边界 + 明确的使用边界」讲清楚底盘护板能做什么、不能承诺什么，避免把「能放上去」当成「适合安装」，最终引导到店按车型核对版型。

- **目标用户**：经常经过施工路段或砂石路面的车主；希望减少底盘关键区域直接暴露的车主；重视新能源车电池与电驱区域日常隔护的车主（`products.ts` `chassis.audience`）。
- **核心诉求**：为前后电机、电池、线束区域增加一道可检查/维护/更换的外部隔护层。
- **转化目标**：微信咨询或到店确认车型与底盘版本 → 举升检查 → 安装。
- **在导航中的位置**：顶部导航「产品中心」下拉 → 服务分类「底盘护板」（`navLabel: 底盘护板`，P0，light_mod 组）。

## 四、逐区块文案

### 1. Hero（`<ChassisHero />`）

- **角标**：底盘升级
- **H1 / 主标题**：铝镁合金底盘护板 五段分区覆盖关键部位（第二行以浅色显示）
- **导语**：覆盖前后电机、电池与线束区域，为日常碎石、泥沙和轻微刮碰增加一道外部隔护。
- **CTA**：①「查看五段结构」（锚点 `#chassis-coverage`）②「了解安装适配」（锚点 `#chassis-fitment`）
- **3 项关键参数**：材质 铝镁合金 / 结构 五段分区 / 外观 黑色 / 银色
- **主图注**：安装前需要举升检查原车底盘结构、固定位置与部件间隙

### 2. 五段分区 + 安装价值（`<ChassisCoverage />`）

- **小标题**：五段分区
- **H2**：从前电机到后电机，按区域覆盖
- **导语**：护板不是一整块通用金属板。不同区域分别成型，再按照对应车型的底盘结构组合安装。
- **5 段结构**：
  1. 01 前电机护板：对应车辆前部电驱区域，在原车底部外侧增加一道隔护。
  2. 02 线束护板：覆盖底盘线束集中区域，减少日常路面异物直接刮碰。
  3. 03 前电池护板：覆盖电池包前段，是五段结构中的主要覆盖区域之一。（重点）
  4. 04 后电池护板：衔接电池包后段，与前电池护板形成连续的底部覆盖。（重点）
  5. 05 后电机护板：对应车辆后部电驱区域，补齐车尾方向的底部隔护。
- **H2（价值）**：安装护板后，车主能得到什么
- **导语**：它的价值不是让车辆变得"撞不坏"，而是为日常路况增加一层可以检查、维护和更换的外部隔护。
- **3 条价值**：减少关键区域直接接触 / 覆盖更完整 / 复杂路况更安心（文案见附录）

### 3. 产品外观（`<ChassisVariants />`）

- **小标题**：产品外观
- **H2**：黑色或银色，结构以车型为准
- **导语**：两张产品图均展示前电机、线束、前电池、后电池与后电机五个区域。不同车型的轮廓、孔位和分段比例会有差异。
- **黑色方案**：深色表面更接近多数原车底部视觉，图中展示五段护板的对应位置。
- **银色方案**：银色表面让压筋与分区轮廓更直观，实际可选外观以车型批次为准。

### 4. 安装适配（`<ChassisFitment />`）

- **小标题**：安装适配
- **H2**：先确认底盘结构，再决定能不能装
- **导语**：底盘护板属于车型适配件。产品轮廓、固定位置、散热与检修边界，都需要结合具体车辆确认。
- **强调句**：不把"能放上去"当作"适合安装" —— 只有版型、固定位置、部件间隙和必要功能区域都确认后，才进入安装环节。
- **4 步核对**：
  1. 01 核对车型与底盘版本：同一车系不同年款和配置的底盘结构可能不同，先确认对应产品版型。
  2. 02 检查固定位置与原车状态：举升后查看原车护板、固定位置和底部状态，再确定安装条件。
  3. 03 避开散热、排水与检修区域：结合实车结构确认必要的散热口、排水口和常用检修位置不被不当遮挡。
  4. 04 安装后复查间隙与紧固：交付前检查固定点、部件间隙和异常声响；发生明显托底后建议再次检查。
