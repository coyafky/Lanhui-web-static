# 洗美养护

## 一、页面定位

> 一句话：用「常见清洁需求 → 3 类服务方案 → 到店流程」把普洗/精洗/轮毂定向清洗讲清楚，强调「服务范围、预计时间与费用会在施工前确认」，引导到店消费。

- **目标用户**：日常通勤、需要基础外观清洁或重点清洁的车主（页面未单列 audience）。
- **核心诉求**：搞清楚普洗/精洗/轮毂清洗分别做什么、要多久、怎么收费。
- **转化目标**：微信咨询 / 到店 → 接车沟通确认服务范围与费用 → 施工 → 完成确认。
- **在导航中的位置**：顶部导航「产品中心」下拉 → 服务分类「洗美养护」（`navLabel: 洗美养护`，P0，car_care 组）。

### 2. 常见清洁需求（`<CarCarePainPoints />`）

- **小标题**：常见清洁需求
- **H2**：从日常清洁到重点处理，按实际车况安排
- **导语**：不同车况需要的清洁程度不同，我们会结合车辆状态说明适合的服务。
- **3 类需求**：
  1. 日常浮尘与轻度泥点：车辆以日常通勤为主，车身有浮尘、轻度泥点或雨后水渍时，普洗可以完成基础外观清洁。
  2. 门缝与边角积污：门缝、边角和玻璃等位置积污较明显时，精洗会在普洗基础上增加更细致的分区处理。
  3. 轮毂发黑与附着物：轮毂有明显刹车粉尘、铁粉或柏油附着时，可单独安排轮毂定向清洗。

### 3. 服务方案（`<CarCareServiceGrid />`，`carCareServiceDetails`）

- **小标题**：服务方案
- **H2**：服务范围、预计时间与费用，会在施工前与您确认
- **导语**：我们会先了解车况和清洁需求，再说明适合的项目；没有必要增加的内容，也会如实告知。
- **3 项服务明细**：

| 服务 | 英文 | 说明 | 适合车况 | 预计时长 | 费用 |
|---|---|---|---|---|---|
| 普洗 | BASIC WASH | 面向日常通勤车辆的基础外观清洁，覆盖车身冲洗、泡沫清洁、擦干与基础轮胎整理。 | 车身有日常浮尘、轻度泥点或雨后水渍，希望完成常规外观清洁 | 接车沟通后确认 | 施工前确认 |
| 精洗 | DETAIL WASH | 在普洗基础上，更细致地处理门缝、边角、玻璃和轮毂等容易积污的位置。具体清洁范围会结合车况确认。 | 车辆较长时间未清洁，门缝和边角积灰明显，或希望进行更完整的外观清洁 | 约 1.5 至 2.5 小时 | 施工前确认 |
| 轮毂定向清洗 | TARGETED WHEEL CLEANING | 针对轮毂上的刹车粉尘、铁粉和柏油等附着物进行清洁。服务前会先检查轮毂表面工艺和脏污情况。 | 轮毂明显发黑，辐条或螺栓位积污较多，常规清洗后仍有附着物 | 约 0.5 至 1 小时 | 施工前确认 |

- **各服务包含项目**：
  - 普洗：车身预洗与泡沫清洁 / 漆面与玻璃外侧清洗 / 车身擦干与缝隙吹水 / 轮胎基础清洁
  - 精洗：预洗与车身分区清洁 / 门缝和边角细节处理 / 玻璃外侧与轮毂清洁 / 清洁完成后共同确认
  - 轮毂定向清洗：轮毂表面与脏污检查 / 轮辐和螺栓位分区清洁 / 针对性处理铁粉与柏油附着物 / 完成后共同查看清洁状态

### 4. 到店流程（`<CarCareServiceFlow />`，`carCareProcess`）

- **小标题**：到店流程
- **H2**：从车况沟通到清洁完成，流程清楚
- **导语**：服务范围、预计时间与费用会根据车型和车况确认，确认后再开始清洁。
1. 01 接车沟通：了解您希望改善的位置，并一起查看车身、边角和轮毂的当前状态。
2. 02 方案确认：说明本次服务范围、预计时间和费用，不适合或没有必要增加的项目会提前说明。
3. 03 按项清洁：按照确认的普洗、精洗或轮毂定向清洗内容，完成对应区域的清洁。
4. 04 完成确认：清洁完成后与您一起查看本次服务区域，并说明后续日常维护建议。
