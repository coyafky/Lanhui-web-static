# 电动踏板

## 一、页面定位

> 一句话：用「老人/小孩/抱娃提物/商务接待」4 个真实上下车场景讲价值，用 3 款款式对比表 + 车型限制说明帮车主选款，最终引导到店确认车型、底盘与电路适配。

- **目标用户**：家用 SUV / MPV / 越野车主、上下车不便的家庭用户、注重原车观感的车主（`products.ts` `electric-steps.audience`）。
- **核心诉求**：给老人小孩一个更低、更清晰的落脚位置；收起后不破坏原车线条；安装不破线束、可靠防水防夹。

### 4. 到店流程（`<ElectricStepServiceFlow />`，`electricStepProcess`）

- **小标题**：到店流程
- **H2**：从车型确认到交付复查，每一步都可追溯
- **导语**：到店交付，统一规范。施工时长取决于车型和款式，具体以到店评估为准。
1. 01 车型确认：确认车型、年款、底盘结构、侧裙高度和家庭成员上下车场景。 → 交付物「车型适配确认单」

4. 04 交付复查：复查固定点、异响、防夹、离地间隙和后续用车注意事项。 → 交付物「交付检查清单 + 复查提醒」

【常见问题】
安装电动踏板需要多久？—— 通常需要 3-5 小时，具体取决于车型结构和踏板款式。部分车型结构复杂可能延长至半天。建议提前预约，到店后评估准确工期。
安装会破坏原车线路吗？—— 蓝辉采用原车信号对接方式，通过专用插头读取门体信号并供电，尽量不改动原车线束。具体接线方式以到店后根据车型结构确认为准。
踏板收起后会不会显得很突兀？—— 收起后踏板尽量贴合车侧底部，不同车型的贴合度有差异，建议到店看同车型的安装效果再决定。
雨天或洗车后踏板会不会进水？—— 产品设计考虑了日常防水，插头和线束有防水保护。但涉水深度超过踏板收起位置时不建议强行通过。洗车时避免高压水枪近距离直冲踏板电机和接口。
如果踏板故障卡住了怎么办？—— 如遇踏板卡住不收回，请勿强行行驶。联系蓝辉门店，我们会尽快安排检查。交付时会告知你异常情况的判断方式和应急处理建议。
