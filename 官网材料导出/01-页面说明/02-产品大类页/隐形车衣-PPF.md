# 隐形车衣（PPF）

## 一、页面定位

> 一句话：把「为什么贴车衣、贴哪一款」讲清楚，用真实参数表和施工逻辑，让新车车主判断该不该贴、该选哪一系列，最终引导到店确认与微信咨询。

- **目标用户**：新车车主、高端车型车主、重视保值率和漆面保护的车主（`products.ts` audience 原文）。
- **核心诉求**：原厂车漆防划痕/防剐蹭/防酸雨鸟粪树胶；用较低成本替代反复抛光补漆；选到靠谱的 TPU 材质与施工。
- **转化目标**：微信咨询（企业微信弹窗）→ 到店看样、确认车型方案 → 施工下单；辅以抖音案例种草。
- **在导航中的位置**：顶部导航「产品中心」下拉 → 服务分类「隐形车衣」（`navLabel: 隐形车衣`，P0，film 组）。

### 2. 选膜指南

- **小标题**：选膜指南
- **H2**：选膜、贴膜，这些坑我们已经帮您踩过了
- **主卡（第一条）**：
  - 徽标：专业团队 · 精准施工
  - H3：智能驾驶车型也能放心贴
  - 正文：智能驾驶感知硬件对贴膜施工精度和车型数据适配度有更高要求。我们拥有经验丰富的专业贴膜师傅团队，施工前对雷达、摄像头位置做精确预留，兼顾漆面保护与智驾功能，不影响正常使用。
- **辅卡 H4 5 条**：
  1. 徽标「无划痕 · 无氧化层」/ 标题「新车是贴膜的推荐时机」/ 正文：新车无划痕、无氧化层，是做漆面防护的理想阶段。提前装贴保护膜，能从源头隔绝各类轻微漆面损伤，不用频繁去做抛光、补漆修复，长期来看反而能省下不少养护成本。
  2. 徽标「拒绝劣质车衣」/ 标题「正品TPU + 专业施工 = 靠谱」/ 正文：旗舰车型选膜不能贪便宜。劣质车衣一两年就发黄、开胶、龟裂，撕膜时还可能损伤原厂漆，得不偿失。
  3. 徽标「7.5-8.5mil 推荐厚度」/ 标题「材质只认脂肪族TPU」/ 正文：PVC是"毁容膜"，选膜只认脂肪族TPU材质。厚度方面，7.5mil-8.5mil是最佳区间——太薄防护不够，太厚影响贴合度和曲面表现。
  4. 徽标「耐黄变 · 抗腐蚀」/ 标题「TPU材质是底线，佛山高温天尤其重要」/ 正文：佛山顺德及珠三角常年高温暴晒，劣质TPH膜一两年就发黄、开裂。至少选脂肪族TPU材质，耐黄变、抗腐蚀，本地高温天实测3年不变色。
  5. 徽标「专业施工更安心」/ 标题「新手车主不建议自己DIY」/ 正文：网上有"不贴车衣、自己打蜡"的省钱攻略，但如果你不是玩车老手，强烈不建议——洗车打蜡稍有不慎就是满车太阳纹。大尺寸车型漆面娇贵，专业的事交给专业的人。

### 3. 决策梳理（`<ProductDetail />` + `<PpfProtectionPrinciples />`）

- **小标题**：决策梳理
- **H2**：从漆面威胁到长效保护，一站式解决
- **导语**：了解车漆每天都在面对什么、隐形车衣如何保护、以及为什么众多车主选择蓝辉。
- **H3（第一段）**：你的车漆每天都在面对什么
- **威胁卡（仅渲染前 4 条 `protectionScenes`）**：
  - 防止树胶叶痕：减少树胶、落叶残留对车漆的腐蚀
  - 防止鸟粪虫尸：降低酸性物质对漆面的伤害
  - 防止酸雨水垢：减少雨水、水垢长期停留造成的漆面问题
  - 防止风沙粉尘：减少细小颗粒对漆面的摩擦伤害
- **H3（第二段，`<PpfProtectionPrinciples />`）**：一层透明保护，降低日常用车对原厂漆的损耗
  - 段导语：隐形车衣覆盖在原厂漆表面，通过功能涂层、TPU 基材与胶层协同作用，减少细小划痕、道路污染和环境物质对漆面的直接影响。
  - 示意图（figcaption）：车衣与原厂漆保护关系 / 保护关系示意，实际膜层厚度不按比例展示；图内三层：透明车衣层（承受日常细纹、污渍与轻微冲击）→ 原厂车漆层（保持原车色泽与漆面完整度）→ 车身钢板层（车身结构基础）
  - 分组「漆面保护表现」：轻微划痕修复 / 柔韧缓冲 / 耐候防护（文案见附录）
  - 分组「日常使用体验」：保持漆面光泽 / 疏水耐污 / 稳定贴合（文案见附录）
  - 尾注：具体表现因产品系列、使用环境和养护方式而异。材质、涂层、胶水与质保信息以对应产品参数为准。
- **H3（第三段）**：为什么选择蓝辉（渲染 `ppf.values` 4 项）：原材料优势 / 制造设备 / 生产工艺 / 技术服务（文案见附录）
- **桥接句**：上面的选膜指南帮你理清思路，接下来找到匹配你需求的系列

你的车漆每天都在面对什么
  · 防止树胶叶痕：减少树胶、落叶残留对车漆的腐蚀
  · 防止鸟粪虫尸：降低酸性物质对漆面的伤害
  · 防止酸雨水垢：减少雨水、水垢长期停留造成的漆面问题
  · 防止风沙粉尘：减少细小颗粒对漆面的摩擦伤害
一层透明保护，降低日常用车对原厂漆的损耗
隐形车衣覆盖在原厂漆表面，通过功能涂层、TPU 基材与胶层协同作用，减少细小划痕、道路污染和环境物质对漆面的直接影响。

漆面保护表现
  轻微划痕修复：在适宜温度下，表层涂层可逐渐减轻洗车细纹和日常轻微划痕。深划痕、破膜或露漆不属于修复范围。
  柔韧缓冲：TPU 基材能够缓冲部分碎石飞溅与轻微剐蹭，降低日常行驶对原厂漆面的直接损耗。
  耐候防护：帮助减缓紫外线、酸雨、鸟粪和树胶等环境因素对漆面产生的长期影响。
日常使用体验
  保持漆面光泽：透明膜层减少洗车细纹与轻微摩擦带来的观感损耗，让原厂漆更容易保持通透和光泽。
  疏水耐污：降低水滴、泥污和道路污染物的附着，减少污渍长期停留，后续清洁更加轻松。
  稳定贴合：压敏胶层贴合车身曲面，配合规范施工和拆除，降低翘边、残胶及漆面损伤风险。
具体表现因产品系列、使用环境和养护方式而异。材质、涂层、胶水与质保信息以对应产品参数为准。
