# 博客分类分页模板（/blog/category/[category]/page/[page]）

## 一、页面定位

> 一句话：某个分类文章超过一页时的「第 2 页及以后」。当前各分类文章都不足 9 篇，因此只生成了各自的第 1 页（且第 1 页会重定向回分类主页）。

- **目标用户**：在某一分类里持续翻页浏览的车主。
- **核心诉求**：在单一品类里连续翻页，不被其它品类打断。
- **转化目标**：浏览 → 阅读详情 → 电话咨询。
- **在导航中的位置**：不在导航；由 `/blog/category/{cat}` 底部的 `<Pagination />` 进入。

## 二、SEO 元信息（每分类每页独立生成）

| 项目 | 内容 |
|---|---|
| Title | `{分类中文名} · 品牌资讯 \| 蓝辉轻改 LANHUI`（注意：Title 不区分页码） |
| Description | `{分类} 分类文章列表。` |
| Canonical | `/blog/category/{cat-english-slug}`（相对路径，**统一指向分类第 1 页**，不写页码） |
| Keywords / 主题词 | 源码未单独提供 |
| OG 图 | 未设置 |
| 结构化数据 | 无页面级 JSON-LD |
| 是否进 sitemap | 否 |

> ⚠️ 注意 SEO 细节：本模板 Metadata 的 Title/Description 不含页码，Canonical 也不区分页——而 `/blog/category/{cat}`（第 1 页）的 Canonical 同样是 `/blog/category/{cat}`。等于分类分页页在元信息层面与分类主页合并，是取舍（避免重复内容）而非遗漏。

## 三、页面结构（自上而下）

| 序号 | 区块 | 组件 | 作用 |
|---:|---|---|---|
| 1 | 顶部导航 | `<Header />` | 全站导航 |
| 2 | Hero | 内联 `<section>` | 眉标 `BLOG · {slug} · 第 {page} 页` + H1 分类名 |
| 3 | 分类文章列表 | 内联 `<section>` + `<CategoryNav />` + `<ArticleCard />` + `<Pagination />` | 分类 Tab（当前分类高亮）+ 本页文章网格 + 分页器 |
| 4 | 页脚 | `<Footer />` | 品牌简介、导航、联系方式、备案 |

> 与分类主页（`/blog/category/[category]`）相比：本页 Hero **无副标题**、列表区**无图标 + H2 标题行与「共 N 篇」**、**无底部 CTA 区块**。

## 四、逐区块文案

### 1. Hero（内联 `<section>`）

- **眉标**：`BLOG · {getCategorySlug(分类)} · 第 {pageNum} 页`
- **H1**：`{分类中文名}`
- （无副标题段落）

### 2. 分类文章列表（内联 `<section>`）

- **分类筛选 Tab（`<CategoryNav />`）**：`全部` → 各分类，当前分类 `active` 高亮
- **文章卡片（`<ArticleCard />`）**：`paginateArticles(getArticlesByCategory(分类), pageNum)`，本页最多 9 篇
- **分页（`<Pagination />`）**：`basePath = /category/{slug}`；URL 规则 `/blog/category/{slug}/page/{n}`，第 1 页回落到 `/blog/category/{slug}`

### 3. 页脚（组件 `<Footer />`）

与首页一致。

## 五、CTA 与转化路径

| 层级 | 按钮/入口 | 文案 | 跳转目标 |
|---|---|---|---|
| 主 CTA | 文章卡片 | 阅读全文 | `/blog/{slug}` |
| 次 CTA | 分类 Tab | 全部 / 门店服务 / 车主案例 / 轮毂 / 改色膜 / 窗膜 | `/blog` 与 `/blog/category/{slug}` |
| 次 CTA | 分页器 | 上一页 / 页码 / 下一页 | `/blog/category/{slug}/page/{n}` |
| 导航 CTA | Header | 查看门店 / 联系我们 | `/agent` / 微信咨询弹窗 |
| 私域入口 | Header / Footer | 联系我们 | 微信咨询弹窗 |

**转化路径**：分类列表 → 分类翻页 → 文章详情 → 电话咨询 / 到店
> 本页无直连电话按钮。

## 七、内链与跳转

**本页链出**：文章详情 `/blog/{slug}`、其它分类 `/blog/category/{slug}`、`全部` → `/blog`、分类分页 `/blog/category/{slug}/page/{n}`。
**链入本页**：分类主页底部分页器；sitemap 未收录。

## 八、技术实现要点

- **generateStaticParams 数据来源**：双重循环——遍历 `getAllCategories()`，对每个分类用 `getTotalPages(getArticlesByCategory(分类).length, BLOG_PAGE_SIZE)` 求总页数，生成 `{ category: getCategorySlug(分类), page: String(n) }`。当前每个分类文章数均 ≤ 9，故每类仅 `page: "1"`，共 **5 个组合**（对应 5 个分类的 `page/1`）。
- **路由注册**：`src/app/blog/category/[category]/page/[page]/page.tsx`。
- **组件复用**：`Header` / `Footer` / `ArticleCard` / `CategoryNav` / `Pagination`；数据函数 `getAllCategories` / `getArticlesByCategory` / `getCategoryBySlug` / `getCategorySlug` / `paginateArticles` / `getTotalPages`。
- **重定向/兜底逻辑**：`pageNum === 1` 时 `redirect("/blog/category/{slug}")`（分类第 1 页归并到分类主页）；分类不存在或越界 `notFound()`。
- **新增一页要改哪里**：**无需手改**——给某分类持续加文章，超过 9 篇后自动生成该分类的 `page/2`（依此类推）。
- **注意事项**：**当前状态**是「有路由、但每个组合都会跳转回分类主页」，实际用户不会停留在此模板页；只有当某分类 > 9 篇时才真正出现「分类第 2 页」内容。
