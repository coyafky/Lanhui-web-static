# 博客分类模板（/blog/category/[category]）

## 一、页面定位

> 一句话：按「改色膜 / 窗膜 / 轮毂 / 门店服务 / 车主案例」把文章归堆，形成有独立描述的分类落地页，承接「改色膜怎么选」这类分类级搜索意图，并作为内链枢纽。

- **目标用户**：对某一品类（如改色膜、窗膜）有明确兴趣、想集中浏览的车主。
- **核心诉求**：快速看到该品类全部文章，判断内容深度与门店专业度。
- **转化目标**：浏览分类内容 → 阅读文章 → 电话咨询。
- **在导航中的位置**：不在主导航；由 `/blog` 与各分类页顶部的 `<CategoryNav />` 分类 Tab 进入。

## 四、逐区块文案

### 1. Hero（内联 `<section>`）

- **眉标**：`BLOG / {getCategorySlug(分类)}`（橙色小字）
- **H1**：`{分类中文名}`
- **副标题**：`CATEGORY_DESC[分类]`，未登记时 `{分类}相关文章，帮助升级决策更透明。`

### 2. 分类文章列表（内联 `<section>`）

- **图标 + H2**：`{分类中文名}`，旁标 `共 {all.length} 篇`
- **分类筛选 Tab（`<CategoryNav />`）**：`全部` → 各分类，当前分类高亮（`active`）
- **文章卡片（`<ArticleCard />`）**：分类徽标 / 日期 / `{N} 分钟阅读` / 标题（H3）/ 描述 / `阅读全文`；封面缺失时显示「蓝辉轻改」文字占位
- **该分类始终是第 1 页**：`paginateArticles(all, 1)`，每页 `BLOG_PAGE_SIZE = 9` 篇
- **空态**：`该分类暂无文章，敬请期待。`
- **分页（`<Pagination />`）**：`basePath = /category/{slug}`；总页数 > 1 时才渲染

### 3. 底部 CTA（内联 `<section>` + `<PhoneCta />`）

- **H2**：想为爱车升级，但不知道从哪开始？
- **正文**：电话咨询顺德大良店，报上车型和需求，获取初步方案与报价
- **按钮**：`18825425068 电话咨询` → `tel:18825425068`（`size="lg"`）

### 4. 页脚（组件 `<Footer />`）

与首页一致。

## 七、内链与跳转

**本页链出**：文章详情 `/blog/{slug}`、分类互相切换 `/blog/category/{其它分类}`、`全部` → `/blog`；当总页数 > 1 时分页 `/blog/category/{slug}/page/{n}`；`tel:18825425068`。
**链入本页**：`/blog` 与其它分类页的 `<CategoryNav />`；文章详情面包屑（到 `/blog`，非分类）；sitemap 未收录。

## 八、技术实现要点

- **generateStaticParams 数据来源**：`getAllCategories()`（从全部已发布文章按「首次出现顺序」去重收集 `category`），映射为 `{ category: getCategorySlug(分类) }`。当前生成 5 个分类页。
- **路由注册**：`src/app/blog/category/[category]/page.tsx`。
- **组件复用**：`Header` / `Footer` / `ArticleCard` / `CategoryNav` / `Pagination` / `PhoneCta`；数据函数 `getCategoryBySlug` / `getCategorySlug` / `getArticlesByCategory` / `paginateArticles` / `getTotalPages`。
- **新增一个分类要改哪里**：① 给文章 frontmatter 写新的 `category` 值（`getAllCategories` 自动纳入 → 自动生成分类页）；② 在 `src/lib/blog.ts` 的 `CATEGORY_SLUGS` 登记「中文名 → 英文 slug」（URL 用英文避免中文动态段编码问题）；③ 可选在 `CATEGORY_DESC` 增补分类描述（不补则用兜底文案）。
- **注意事项**：分类 Tab 的「全部」指向 `/blog`；`/blog/category/{slug}` 恒为第 1 页，第 2 页起走 `/blog/category/{slug}/page/{n}`（该路由会把 `page/1` 重定向回本页）。
