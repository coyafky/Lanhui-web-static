# 窗膜套餐详情模板（/product/window-film/[packageSlug]）

## 一、页面定位

> 一句话：每个「前挡 + 侧后挡」膜材组合一个页，把汽车窗膜总页里的 7 个套餐（春分/谷雨/小满/芒种/白露/网红/养生）拆成可被搜索与 AI 逐条引用的参数页，只讲搭配、特性、参数、质保，**不出现价格**。

- **目标用户**：已了解汽车窗膜、在具体套餐之间做选择的车主。
- **核心诉求**：看懂「前挡用什么膜、侧后挡用什么膜、各参数代表什么、质保多久」。
- **转化目标**：选定方向 → 到店 / 电话咨询（本页自身无直连电话按钮，靠 Header / Footer）。
- **在导航中的位置**：不在主导航；由「汽车窗膜」总页（`/product/window-film`）的套餐卡片进入。

## 八、技术实现要点

- **generateStaticParams 数据来源**：`getAllWindowFilmPackageSlugsWithDetails()` → 取汽车窗膜总页基础套餐 slug（`getAllWindowFilmPackageSlugs()`）与详情文案（`windowFilmDetails` 的 key）的**交集**，映射为 `{ packageSlug }`。当前 **7 个套餐页**：`chunfen` / `guyu` / `xiaoman` / `mangzhong` / `bailu` / `wanghong` / `yangsheng`。
- **数据合并**：`getWindowFilmPackageWithDetails(slug)` = `products.ts` 的基础数据（name/models/audience/frontProduct/frontParams/rearProduct/rearParams/warranty）⊕ `window-film-details.ts` 的详情文案（positioning/headline/summary/painPoints/benefits/scenarios/parameterNotes/imagePrompt）。
- **路由注册**：`src/app/product/window-film/[packageSlug]/page.tsx`；渲染主体组件 `src/components/window-film/WindowFilmPackageDetail.tsx`。
- **布局复用**：`src/app/product/layout.tsx` 统一注入 `<Header />` / `<Footer />`；`PhoneCta` 等不在本页。
- **新增一页要改哪里**（**两处都要改**）：
  1. `src/lib/products.ts` 的「汽车窗膜」产品 `packages` 数组，新增 `{ slug, name, models, audience, frontProduct, frontParams, rearProduct, rearParams, warranty }`；
  2. `src/lib/window-film-details.ts` 的 `windowFilmDetails`，为同一 `slug` 新增详情对象（含 `positioning` / `headline` / `benefits` / `parameterNotes` 等）。
  - 仅两处齐备才会生成详情页（交集逻辑）；同时会出现在总页套餐卡与 sitemap。
- **注意事项**：改动参数文案要同步 `frontParams`/`rearParams` 与 `parameterNotes[].params` 两处，避免参数前后不一致。
