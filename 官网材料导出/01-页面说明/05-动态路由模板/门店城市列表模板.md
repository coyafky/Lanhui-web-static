# 门店城市列表模板（/agent/[slug]/[city]）

## 一、页面定位

> 一句话：城市级门店列表页——「{市}有哪些蓝辉轻改门店」，比省级页更精准，承接「佛山汽车贴膜门店」「顺德大良汽车轻改」等城市搜索意图，是进「门店详情」前最后一层列表。

- **目标用户**：明确了城市、想找本地门店的车主。
- **核心诉求**：看到本市全部门店，含地址、电话、营业时间。
- **转化目标**：进门店详情 → 拨打电话 `tel:` / 到店。
- **在导航中的位置**：不在主导航；由省级页「按城市浏览」与面包屑进入。

## 四、逐区块文案

### 1. Hero + 面包屑（内联 `<section>`）

- **面包屑**：首页 / 全国门店 / `{省份名}` / `{cityData.label}`（前三级可点，末级当前页）
- **H1**：`{cityData.label}门店`
- **统计句**：`{cityData.label}共有 {cityData.storeCount} 家蓝辉轻改门店`（数字橙色加粗）

### 2. 门店列表（内联 `<section>` + `<StoreCard />`）

- **图标 + H2**：门店列表
- **右侧小字**（仅当有门店时）：按门店等级排序 · 旗舰优先
- **门店卡片（`<StoreCard />`）**：门头图（左上 `LANHUI` / 右上等级 Badge）、门店名、地址、电话、营业时间、「查看详情」→ `/agent/store/{id}`

### 3. 页脚（组件 `<Footer />`）

与首页一致。

## 八、技术实现要点

- **generateStaticParams 数据来源**：先取 `listPublishedProvinces()` 的省份 slug，再对每个省调用 `listStaticCityParams(provinceSlug)`（基于 `listPublishedCities`，只含「该市有门店」的城市），合并为 `{ slug, city }`。当前 **1 个城市页**：`guangdong/foshan`（佛山）。
- **`dynamicParams = false`**：未枚举的 `slug/city` 组合一律 404。
- **路由注册**：`src/app/agent/[slug]/[city]/page.tsx`。
- **组件复用**：`Header` / `Footer` / `StoreCard` / `sortStoresByLevel`；数据函数 `listPublishedCities` / `listStores` / `listStaticCityParams` / `listPublishedProvinces`。
- **新增一页要改哪里**：**在 `src/lib/store.ts` 的 `stores` 新增一条门店**并填 `province` / `city` slug，`listPublishedCities` 自动纳入该市 → 自动生成城市页；城市名标签由 `mainland-regions.ts` 的行政区目录提供（`cityLabel` 在门店数据里冗余存一份）。
- **注意事项**：仅生成「有已开放门店」的城市页；`cityCode` 前缀为 `419/429/469/659` 的省直辖县级单位不生成城市落地页（见 `store-query.ts` 过滤逻辑）。
