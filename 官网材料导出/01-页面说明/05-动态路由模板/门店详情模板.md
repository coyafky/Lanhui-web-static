# 门店详情模板（/agent/store/[id]）

## 一、页面定位

> 一句话：单家门店的「落地页」——门头实景 + 地址 / 电话 / 营业时间一键拨号，是整站地域流量的最终转化节点，也是本地 SEO（LocalBusiness）的载体。

- **目标用户**：准备到店或打电话咨询的本地车主。
- **核心诉求**：确认门店地址、电话、营业时间、门店等级；一键拨号或导航。
- **转化目标**：拨打电话 `tel:` / 到店。
- **在导航中的位置**：不在主导航；由 `/agent/{省}/{市}` 的门店卡片进入。

## 二、SEO 元信息（每门店独立生成）

| 项目 | 内容 |
|---|---|
| Title | `{store.name} \| 蓝辉轻改 LANHUI` |
| Description | `{store.name}位于{store.address}，提供蓝辉轻改轻改装备与汽车膜系服务。` |
| Canonical | `/agent/store/{id}` |
| Keywords / 主题词 | 源码未单独提供 |
| OG 图 | 未设置 |
| 结构化数据 | 两条 JSON-LD：`LocalBusiness`（`generateLocalBusinessSchema(store)`，含地址/电话/经纬度/营业时间）+ `BreadcrumbList`（首页 / 全国门店 / 省 / 市 / 门店名） |
| 是否进 sitemap | 是（`routeEntry(`/agent/store/${s.id}`, 0.7, "monthly")`） |

## 四、逐区块文案

### 1. Hero + 面包屑（内联 `<section>`）

- **面包屑**：首页 / 全国门店 / `{provinceLabel}` / `{cityLabel}` / `{store.name}`（前四级可点，末级当前页）
- **角标**：灰色 `LANHUI` + `<StoreLevelBadge variant="card" />`（如「旗舰店」）

  - 等级 Badge（`variant="inline"`）
  - 简介：`{store.description}`
  - 联系信息卡：
    - 门店地址：`{store.address}`
    - 联系电话：`{store.phone}`（链接 `{store.phoneTel}`）

  - CTA 按钮：`电话咨询`（→ `tel:`）+ `返回{store.cityLabel}`（→ `/agent/{省}/{市}`）

## 八、技术实现要点

- **generateStaticParams 数据来源**：`listStaticStoreParams()` → `listStores()`（过滤 `isActive !== false`）映射为 `{ id }`。当前 **1 个门店页**：`100001`（蓝辉轻改顺德大良店）。
- **`dynamicParams = false`**：未枚举的 id 一律 404。
- **路由注册**：`src/app/agent/store/[id]/page.tsx`。
- **组件复用**：`Header` / `Footer` / `StoreLevelBadge`；数据函数 `findStore`；结构化数据 `generateLocalBusinessSchema` / `generateBreadcrumbSchema`。
- **数据链路**：门店数据在 `src/lib/store.ts` 的 `stores` 数组（含 id/name/省市/district/address/phone/phoneTel/location(GCJ-02)/businessHours/description/image/level/isActive）。
- **新增一页要改哪里**：**在 `src/lib/store.ts` 的 `stores` 数组新增一条门店对象**，`id` 唯一（字符串，如 `100002`），`isActive: true`；`generateStaticParams` 自动生成 `/agent/store/{id}`。若新门店在现有省/市之外，还会顺带生成对应省页/城市页。图片放到 `public/images/stores/`。
- **注意事项**：门店详情页的门头图路径是**源码硬编码** `/images/stores/image.webp`，新增门店若用不同图片，需同步修改 `src/app/agent/store/[id]/page.tsx`（当前所有门店共用一张占位门头）。
