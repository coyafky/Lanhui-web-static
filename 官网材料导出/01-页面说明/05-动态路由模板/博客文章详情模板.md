# 博客文章详情模板（/blog/[slug]）

## 一、页面定位

> 一句话：一篇文章一个页，把「选膜干货 / 轻改科普 / 车主案例」沉淀为可被搜索与 AI 引用的长内容，用文末电话 CTA 把读者引到顺德大良店。

- **目标用户**：处在选购/避坑阶段、通过搜索或站内推荐进入的车主。
- **核心诉求**：读到可信、专业、可操作的知识；判断门店是否靠谱。
- **转化目标**：读完文章 → 电话咨询 / 到店。
- **在导航中的位置**：不在主导航；由「品牌资讯」列表（`/blog`）、分类列表、文章卡片、上一篇/下一篇互链进入。

## 二、SEO 元信息（每篇文章独立生成）

| 项目 | 内容 |
|---|---|
| Title | `{文章标题} \| 蓝辉轻改 LANHUI` |
| Description | 文章 frontmatter 的 `description`（缺失时用正文前 60 字兜底） |
| Canonical | `https://lanhuiqinggai.com/blog/{slug}`（绝对地址） |
| Keywords / 主题词 | 源码未单独提供 |
| OG 图 | 有 `featuredImage` 时用 `{SITE_URL}{featuredImage}`，否则不设置（继承 layout `/images/social/og-default.png`）；`openGraph.type = article`，含 `publishedTime` |
| 结构化数据 | 两条 JSON-LD：`Article`（headline/description/image/datePublished/dateModified/author=Organization 蓝辉轻改 LANHUI/publisher/mainEntityOfPage）+ `BreadcrumbList` |
| 是否进 sitemap | 是（`src/app/sitemap.ts` 用 `getAllArticles()` 动态枚举全部已发布文章） |

## 三、页面结构（自上而下）

| 序号 | 区块 | 组件 | 作用 |

## 四、逐区块文案

### 1. 面包屑（组件 `<Breadcrumbs />`）

首页 / 品牌资讯 / `{文章标题}`（前两级可点击，末级为当前页）。

### 2. 文章头部（内联 `<header>`）

- **分类徽标**：`{article.category}`（橙色描边小标签）
- **H1**：`{article.title}`
- **发布日期**：`{formatArticleDate(publishedAt)}`，如 `2026年8月5日`
- **阅读时长**：`{readingMinutes} 分钟阅读`（中文按约 400 字/分钟估算，最少 1 分钟）

### 3. 正文（组件 `<ArticleContent />`）

Markdown 由 `markdown-it`（`html:false`）渲染，套 `.prose-article` 深色品牌样式。H2/H3、段落、列表、表格等均由文章源文件决定，模板不写死。

### 4. 上一篇 / 下一篇（内联 `AdjacentLink`）

- **上一篇**：比当前更新的文章（`getAdjacentArticles().prev`，列表倒序中的前一条），左侧、带左箭头、「上一篇」。
- **下一篇**：比当前更旧的文章（`.next`），右侧对齐、带右箭头、「下一篇」。
- 仅当存在时才渲染；点击进入 `/blog/{相邻文章 slug}`。

### 5. 底部 CTA（内联 `<section>` + `<PhoneCta />`）

- **H2**：关于文章内容，想进一步了解？
- **正文**：蓝辉轻改顺德大良店提供方案咨询与施工预约，营业时间 09:00-18:00
- **按钮**：`18825425068 电话咨询` → `tel:18825425068`

### 6. 页脚（组件 `<Footer />`）

与首页一致（品牌简介 / Slogan / 快捷导航 / 产品中心 / 联系方式 / 备案）。

## 七、内链与跳转

## 八、技术实现要点

- **generateStaticParams 数据来源**：`getAllArticles()`（读 `src/content/articles/*.md`，过滤 `draft:true`、按 `publishedAt` 倒序、拒绝重复 slug），映射为 `{ slug }`。构建时枚举全部已发布文章。
- **路由注册**：`src/app/blog/[slug]/page.tsx`（Next.js App Router，`output: export` 静态导出）。
- **组件复用**：`Header` / `Footer` / `Breadcrumbs` / `ArticleContent` / `PhoneCta`；数据函数 `getArticleBySlug` / `getAdjacentArticles` / `formatArticleDate`。
- **新增一篇文章要改哪里**：在 `src/content/articles/` 新增一个 `.md` 文件，frontmatter 必填 `title`（缺会构建报错）、`publishedAt`（必须 `YYYY-MM-DD`）；可选 `slug`（缺省用文件名）、`description`、`category`（缺省「品牌资讯」）、`featuredImage`、`draft`。无需改路由文件，`generateStaticParams` 自动纳入。
- **注意事项**：`slug` 全局唯一，重复会构建报错；正文无原始 HTML 注入，安全；`category` 值决定它出现在哪个分类页。

第一步：分清 PVC 与 TPU 材质 —— 改色膜按基材主要分两类：PVC 改色膜：价格亲民，颜色选择多，是市场主流。寿命一般 2~3 年，适合想频繁换色、控制预算的车主。TPU 改色膜：在改色的基础上增加了自修复能力，能抵抗轻微划痕，寿命更长，但价格明显更高。适合想要"颜色 + 防护"一步到位的车主。选择建议很简单：短期尝鲜选 PVC，长期持有选 TPU。如果只是想过个两年换个颜色，多花钱上 TPU 意义不大。
第二步：品牌膜为什么贵？—— 同样是 PVC，品牌膜和非品牌膜的差距主要体现在三方面：胶层稳定性。劣质膜的胶层容易留胶，撕膜时把原厂漆带下来，修复成本远超贴膜本身。延展性与施工性。品牌膜延展性好，包边、收边更服帖，边角不易起翘；劣质膜施工时容易"硬掰"，埋下翘边隐患。颜色与质保。品牌膜颜色稳定、有质保体系；小厂膜色差大、褪色快，出问题基本找不到人。选膜时认准品牌授权门店，并要求提供质保卡或电子质保凭证，这是最直接的避坑手段。
第三步：施工工艺决定最终效果 —— 膜只是材料，效果看施工。判断一家店施工是否到位，可以关注这几点：是否在无尘车间施工——灰尘是起泡、麻点的主要来源；包边是否完整——门缝、把手、logo 处是否贴合无翘起；是否拆装部分饰件施工——真正专业的做法是拆件贴，追求完整性而不是图快。改色完成当天要仔细检查，当场发现问题当场处理，不要等到离店后才发现。
第四步：别忘了备案 —— 改色面积超过车身颜色 30% 时，需要在变更后 10 日内到车管所办理变更登记。施工前可以问店家是否提供备案指引或代办协助。蓝辉轻改顺德大良店在交车时会同步告知备案流程，避免车主因为漏备案被查。
