# 代理商城市页模板（/agent/[slug]，实际为省级门店聚合页）

> 命名说明：文件名沿用任务约定。该路由的 `[slug]` 实际是**省份 slug**（如 `guangdong`），生成的是「省级门店聚合页」——列出该省覆盖的城市入口 + 省内全部门店。「城市级列表页」见 `门店城市列表模板.md`（`/agent/[slug]/[city]`）。

## 一、页面定位

> 一句话：按省份聚合门店，让用户先确定「哪个省 → 哪些城市有店 → 哪家店离我近」，是「全国门店」（`/agent`）与「城市列表 / 门店详情」之间的中间层，也承担「{省}汽车轻改门店」的地域搜索意图。

- **目标用户**：想找某省内蓝辉轻改门店的车主。
- **核心诉求**：看到本省覆盖城市与全部门店列表。
- **转化目标**：找到门店 → 进城市列表 / 门店详情 → 电话 / 到店。
- **在导航中的位置**：不在主导航；由 `/agent`（全国门店）与面包屑进入。

## 四、逐区块文案

### 1. Hero + 面包屑（内联 `<section>`）

- **面包屑**：首页 / 全国门店 / `{province.label}`（前两级可点，末级当前页）
- **H1**：`{province.label}门店`
- **统计句**：`当前在 {province.label} 已开放 {province.storeCount} 家门店，覆盖 {province.cityCount} 个城市`（关键数字橙色加粗）

### 2. 按城市浏览（内联 `<section>`）

- **图标 + H2**：按城市浏览
- **城市卡片**（`listPublishedCities(slug)`）：左侧城市名 `{city.label}`，右侧角标 `{city.storeCount} 家` + 右箭头；点击进 `/agent/{省 slug}/{市 slug}`
- **空态**：源码未提供（无门店的城市已被 `listPublishedCities` 过滤，故通常至少 1 个）

### 3. 省内门店（内联 `<section>` + `<StoreCard />`）

- **图标 + H2**：省内门店
- **右侧小字**：按门店等级排序 · 旗舰优先
- **门店卡片（`<StoreCard />`）**：门头图（左上 `LANHUI` 角标 / 右上等级 Badge）、门店名、地址、电话、营业时间、「查看详情」→ `/agent/store/{id}`

### 4. 页脚（组件 `<Footer />`）

与首页一致。

## 八、技术实现要点

- **generateStaticParams 数据来源**：`listStaticProvinceParams()` → 基于 `listPublishedProvinces()`，只返回「存在已开放门店」的省份，映射为 `{ slug }`。当前 **1 个省份**：`guangdong`（广东省）。
- **`dynamicParams = false`**：未在 `generateStaticParams` 枚举的 slug 一律 404，不做运行时兜底。
- **路由注册**：`src/app/agent/[slug]/page.tsx`。
- **组件复用**：`Header` / `Footer` / `StoreCard` / `sortStoresByLevel`；数据函数 `listPublishedProvinces` / `listPublishedCities` / `listStores` / `listStaticProvinceParams`。
- **数据链路**：省份/城市行政区目录来自 `src/lib/regions/mainland-regions.ts`；门店来自 `src/lib/store.ts` 的 `stores`；`store-query.ts` 仅在「有门店」的省份/城市上生成页面。
- **新增一页要改哪里**：**在 `src/lib/store.ts` 的 `stores` 数组新增一条门店**（填 `province` slug 等），`listPublishedProvinces()` 会自动把对应省份纳入 → 自动生成该省页；已有省份再开门店只会更新计数。省份目录本身在 `mainland-regions.ts`，一般不动。
- **注意事项**：页面只展示「已开放门店」的省份，避免生成无服务能力的地域页。
