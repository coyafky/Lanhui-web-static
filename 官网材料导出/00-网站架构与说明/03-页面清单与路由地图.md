## 七、sitemap 覆盖情况

### 7.1 sitemap 生成逻辑（`src/app/sitemap.ts`）

sitemap 在构建时由 `sitemap.ts` 动态生成，来源分 9 组：

```ts
return [
  ...staticRoutes,        // 首页 / 产品中心 / 品牌 / 历程 / 联系 / 门店 / 博客（7 条）
  ...brandRoutes,         // ALL_BRANDS 全量（含 planned）→ 12 条
  ...modelRoutes,         // ALL_MODELS 全量 → 19 条
  ...serviceRoutes,       // ALL_SERVICES 中 status==="live" → 11 条
  ...windowFilmRoutes,    // windowFilmDetails 键 → 7 条
  ...legacyProductRoutes, // 旧 slug 归一后的 canonical（本次实测为 0 新增）
  ...provinceRoutes,      // 已发布省份页 → 1 条
  ...cityRoutes,          // 已发布城市页 → 1 条
  ...storeRoutes,         // 门店详情页 → 1 条
  ...blogRoutes,          // 已发布文章 → 15 条
];
```

### 7.2 实测结果（`out/sitemap.xml`）

| 分组 | 数量 |
|---|---:|
| 静态核心路由 | 7 |
| 品牌系列页 | 12 |
| 车型页 | 19 |
| live 服务分类页 | 11 |
| 窗膜套餐页 | 7 |
| 已发布省份/城市/门店页 | 3 |
| 博客文章页 | 15 |
| **合计** | **74** |

- 域名：全部为裸域 `https://lanhuiqinggai.com`（由 `src/lib/site-url.ts` 单源提供）
- `lastmod`：构建时统一取 `new Date()`（非文章真实更新时间）
- changefreq / priority：按路由优先级映射（P0→0.9、P1→0.8、P2→0.7）

### 7.3 不进 sitemap 的页面（以源码逻辑为准）

| 不收录的页面 | 数量 | 原因 |
|---|---:|---|
| `/product/tei-brake/[slug]` 33 个型号详情页 | 33 | 未加入 sitemap 路由组，抓取依赖总页内链（已知待办） |

## 八、一句话总结

官网共 **59 个路由定义、120 个内容页**；其中 **74 个 URL 进 sitemap**，**46 个页面（主要是 33 个 TEI 型号页 + 12 个博客分类/分页页 + 1 个 planned 页）不进 sitemap**。
