# 内容数据模型与修改入口

> 核对：2026-10-24，本地源码快照。此页说明“数据在哪里、谁确认、改后看什么”，字段定义以对应 TypeScript 文件为准。

| 内容 | 主要来源 | 发布条件与注意点 | 验收页面 |
|---|---|---|---|
| 品牌名称、电话、地址、营业时间 | `src/lib/brand.ts`；门店记录在 `src/lib/store.ts` | 两处有重复事实，修改时逐项对照；由门店负责人确认 | 首页、页头页脚、`/contact`、门店页、结构化数据 |
| 品牌/车型/服务路由 | `src/lib/product-routes.ts` 的 `ALL_BRANDS`、`ALL_MODELS`、`ALL_SERVICES` | `canonicalPath` 是正式路径；`status` 有 `live/planned`。新增条目还要有实际页面和内容 | 产品中心、导航、目标页、sitemap、llms.txt |
| 服务与车型项目 | 对应 `src/lib/*-products.ts`、`*-page-config.ts` 和页面 import | 年款、配置、施工项目和参数要核原始资料；`projectCount` 不等于自动验收 | 对应服务/车型页 |
| 轮毂目录 | `src/lib/wheel-catalog*.ts` 与生成的 `wheels.data.ts` | 只通过 `npm run wheels:data` 的管线更新；不得手改生成文件 | `/product/wheels` 与详情页 |
| 窗膜套餐 | `src/lib/window-film-details.ts` 等窗膜数据文件 | 名称、参数、说明与套餐详情页一致；参数有实际核验边界 | `/product/window-film` 与套餐页 |
| 门店目录 | `src/lib/store.ts` + `src/lib/store-query.ts` | 仅公开已确认且 `isActive !== false` 的门店；省/市页面只为有开放门店的地区生成 | `/agent`、省/市/门店页 |
| 博客文章 | `src/content/articles/*.md` + `src/lib/blog.ts` | frontmatter 含 `slug/title/description/category/publishedAt/draft` 等；`draft: true` 不进入已发布列表 | 博客列表、分类、文章、sitemap |
| 图片 | `public/images/` 与各数据/页面中的路径 | 原图与授权记录单独保存；更新图片后检查路径、alt、尺寸、资源加载 | 引用图片的所有页面 |

目前源码注册表为 48 品牌、70 车型、15 服务条目，已发布文章 23 篇、开放门店 1 家。这些是本地源码数字，不能推断线上同步完成。
