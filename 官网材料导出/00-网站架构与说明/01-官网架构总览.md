# 蓝辉轻改官网架构总览

> 源码快照：2026-10-24，本地工作区（含未提交改动）。数据取自 `src/app/`、`src/lib/product-routes.ts`、`src/lib/blog.ts`、`src/lib/store-query.ts` 和 `src/app/sitemap.ts`。这些数字不代表当前线上版本；线上基线另见 `work/RELEASE-20261022.md`。

## 网站做什么

蓝辉轻改官网提供品牌介绍、产品与车型适配说明、门店联系方式和博客内容。访问路径通常是“搜索或内容入口 → 服务/车型页 → 电话、微信或到店咨询”。网站没有登录后台、订单系统和运行时数据库；页面和内容在构建时导出到 `out/`，再由静态 Web 服务器提供访问。

## 信息架构

```text
/                         首页
/product                  产品中心
  /product/<服务>         膜系、轻改装备、座舱内饰、养护
  /product/<品牌>         品牌系列
  /product/<品牌>/<车型>  车型适配与升级说明
  /product/wheels/<型号>  轮毂详情（动态模板静态导出）
/agent                    门店网络 → 省/市/门店详情
/blog                     文章列表 → 分类/分页/文章
/brand                    品牌介绍、历程、集团页
/contact                  联系方式
/robots.txt /sitemap.xml /llms.txt  搜索与 AI 导航文件
```

## 内容如何变成网页

1. 业务负责人确认事实与图片使用权。
2. 开发者修改 `src/lib/` 数据、`src/content/articles/` 文章、`src/app/` 页面或 `public/images/` 图片。
3. 本地预览、核对页面事实，执行 `npm run check:static`。
4. 授权发布人将经过验收的构建产物发布到静态服务器，并核对线上页面与资源。

网页展示内容由多个文件共同决定。路由注册表负责品牌、车型、服务路径；具体参数和项目内容在相应数据模块或页面配置中；图片在 `public/images/`。不要以旧导出材料替代源码，也不要把本地改动视为已经上线。
