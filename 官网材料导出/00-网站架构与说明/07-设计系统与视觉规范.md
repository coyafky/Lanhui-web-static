# 设计系统与视觉维护

> 核对：2026-10-24。正式设计约束以仓库根目录 `DESIGN.md`、`rules/ui.md` 和当前页面组件为准；本页只提供交接用速查，不复制会过期的组件数量与颜色使用次数。

## 当前可见的视觉方向

网站以深色背景、白色正文和橙色行动强调为主。品牌/车型系列的局部强调色在 `src/lib/product-routes.ts` 的 `accentColor` 中登记。页面组件大量使用 Tailwind 类；基础 UI token 在 `src/app/globals.css`。新增品牌或修改色彩时，应核对注册表与具体组件的颜色映射，再做浏览器验收。

## 改视觉时先确认

| 检查项 | 维护要求 |
|---|---|
| 页面层级 | 一个清晰主标题，服务内容、适配边界和咨询入口可被找到 |
| 图片 | 与车型/年款/项目相符；来源、授权、替代文本和移动端裁切已核对 |
| 手机端 | 导航、页签、电话/微信按钮和长表格可用；不要遮住内容 |
| 吸顶元素 | 遵守 `rules/ui.md` 与当前 Header 高度和层级约束 |
| 交互 | 点击、键盘焦点、错误/空状态和减少动画偏好按实际组件核对 |
| 文案 | 不标价格，不使用极限词；参数与适配说明有边界 |

UI/样式/路由/图片变化后，按 `.agents/skills/lanhui-qa/` 的项目档案与其通用 QA 方法进行浏览器检查；先读 `PITFALLS.md`，避免把本地 3000 端口的其他项目误当本站。项目默认预览端口为 **3100**。验收结果要记录目标 URL、设备宽度、截图与问题，不把静态长图评审替代可交互检查。

旧视觉评分和页面截图只作历史参考；当前页面以源码、`DESIGN.md` 和最新浏览器结果为准。
