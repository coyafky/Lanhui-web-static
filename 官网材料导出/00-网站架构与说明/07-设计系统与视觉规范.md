# 设计系统与视觉规范

> 官网整体是**深色（dark-first）工业感 + 橙色点睛**的汽车轻改风格。全站强制深色主题：`<html className="... dark">`、`<body className="bg-zinc-950 text-white">`。

## 一、色彩系统

### 1.1 基础色板（Tailwind 4 内置 zinc / orange）

| 用途 | 色值 | 实测用法（出现次数） |
|---|---|---|
| 页面主背景 | `bg-zinc-950`（≈ #09090b） | 320 处 |
| 分区深背景 | `bg-black` | 94 处 |
| 主文字 | `text-white` | 全站 |
| 次要文字 | `text-zinc-300 / text-zinc-400 / text-zinc-500` | 正文/说明/弱化 |
| 卡片/分区边框 | `border-zinc-900`（125 处）、`border-zinc-800`（298 处） | 卡片与分隔线 |
| **品牌强调色** | **orange**（`text-orange-400` 301 处、`orange-500`） | 标题 eyebrow、CTA、链接、勾选 |
| 次级强调（蓝系） | `blue / cyan / sky` | 品牌页主题、OG 图底纹（#A8C5E8 / #7BA3D1 / #5B83B0） |

### 1.2 设计令牌（`globals.css` 的 `:root` / `.dark`，oklch 定义）

## 二、字体

| 项 | 定义（`globals.css` 的 `@theme`） |
|---|---|
| `--font-sans` | `ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif` |
| `--font-mono` | `ui-monospace, SFMono-Regular, "SF Mono", Menlo, Consolas, monospace` |

- **未引入 Web 字体 / 未用 `next/font`**，直接用系统字体栈（利于性能与首屏）

## 三、间距 / 圆角 / 阴影

### 3.1 圆角体系（`--radius: 0.625rem` ≈ 10px）

| 令牌 | 计算 | 约值 |
|---|---|---|
| `--radius-sm` | radius × 0.6 | 6px |
| `--radius-md` | radius × 0.8 | 8px |
| `--radius-lg` | radius × 1.0 | 10px |
| `--radius-xl` | radius × 1.4 | 14px |

## 四、移动优先断点策略

Tailwind 4 默认断点（移动优先：先写默认小屏，再用前缀叠加）:

| 前缀 | 最小宽度 | 用途（本项目实测） |
|---|---|---|
| （无） | 0 | 手机基准样式 |
| `sm:` | 640px | 平板竖屏/大屏手机，出现次数 **948** |
| `md:` | 768px | 平板，**905** |
| `lg:` | 1024px | 桌面，**843** |
| `xl:` | 1280px | 大屏，**14**（极少用） |

**实测习惯**：`sm`/`md`/`lg` 三个断点被高频使用（均 800+ 处），`xl` 几乎不用——说明设计以「手机/平板/常规桌面」三段式为主，优先保证小屏体验。

典型响应式写法：

```
text-3xl sm:text-4xl md:text-6xl            // 标题逐级放大
px-4 sm:px-6 lg:px-8                        // 容器内边距
flex w-full flex-col gap-3 sm:w-auto sm:flex-row sm:gap-4   // CTA 竖排→横排
grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3              // 卡片网格
```

## 六、博客正文样式（`.prose-article`）

markdown-it 输出的 HTML 由 `globals.css` 的 `.prose-article` 统一美化，保持全站深色橙调：

| 元素 | 样式 |
|---|---|
| 正文 | 颜色 `#d4d4d8`（zinc-300），行高 1.85 |
| h2 | 1.5rem 加粗白色 + 底部 1px 分隔线 |
| 链接 | `#fb923c`（orange-400），下划线 offset 3px，hover 变 `#fdba74` |
| 引用 blockquote | 左侧 3px 橙色边 + 橙色 6% 背景 |
| 行内代码 | 白 7% 背景 + `#fdba74` 文字 |
| 代码块 | `#18181b`（zinc-900）底 + 圆角 |
| 表格 | 可横向滚动，表头白 4% 背景，行 hover 橙色 4% |
| 图片 | 居中、圆角 0.75rem、1px 边框 |
| 任务列表 checkbox | accent-color `#f97316`（orange-500） |

## 七、无障碍与交互规范（源码实测）

| 项 | 做法 |
|---|---|
| 跳转内容 | `<SkipToContent />` + 主内容 `id="main-content"`、`tabIndex={-1}` |
| 导航语义 | Header `<nav aria-label="主导航">`、移动菜单 `aria-label`、下拉 `aria-expanded` |
| 焦点管理 | `use-focus-trap`（弹窗）、`focus-visible:ring-3` |
| 色彩强制 | `<html class="dark">` + `suppressHydrationWarning` |
| 图片 alt | 全站产品图统一带 alt（审计抽检 21/21 齐全） |

## 八、一句话总结

设计语言 = **深色 zinc 底 + 橙色点睛 + 圆角卡片 + 移动优先三段式**；组件复用集中在 `ui/`（原子）、`shared/`（弹窗等共享件）与 `vehicle-page/`（车型页区块），车型页通过 `theme` 字段切换局部强调色。
