# 蓝辉轻改官网｜零基础交接从这里开始

这套材料面向**没有编程经验**的网站接手人。建议按顺序阅读：

1. [09-零基础交接操作手册.md](09-零基础交接操作手册.md)：网站如何从资料变成网页、日常工作、验收与交接。
2. [11-维护模块操作卡.md](11-维护模块操作卡.md)：按“博客、门店、产品、图片、SEO”等任务找入口与验收点。
3. [10-网站文件逐项批注.md](10-网站文件逐项批注.md)：不知道某个源码、脚本或规则文件做什么时查这里。
4. [12-图片资源逐项目录.md](12-图片资源逐项目录.md)：查找 `public/images/` 的图片文件。
5. [13-官网运营与维护方案.md](13-官网运营与维护方案.md)：运营节奏、责任分工、内容优先级、咨询台账和故障处理。

当前源码规模及完整路由请看 [01-官网架构总览.md](01-官网架构总览.md) 与 [03-页面清单与路由地图.md](03-页面清单与路由地图.md)。`01-页面说明/` 的旧逐页资料是历史快照，先看其目录说明，再与页面源码和本地预览核对。

**先记住：** 网站没有登录后台；本地修改不会自动上线。业务事实由负责人确认，源码修改交开发者，发布交授权负责人。旧版逐页说明和历史部署数字使用前要与当前源码、构建结果及线上页面核对。

交接时把本目录连同原始图片、授权记录、业务联系人和最近验收记录一起移交。仓库内的 `rules/`、`adr/`、`specs/`、`work/` 是本地文档，不会随普通 Git 仓库克隆自动带过去。
