## 二、配置文件核实

### `next.config.ts`

```ts
const nextConfig: NextConfig = {
  output: "export",        // 纯静态导出，产物在 out/
  trailingSlash: true,     // 全站 URL 统一带尾斜杠
  images: {
    unoptimized: true,     // 关闭 Next 图片优化（静态站无服务端）
    formats: ["image/avif", "image/webp"],
  },
};
```

## 四、渲染模式：全静态预渲染（SSG）

| 维度 | 现状 |
|---|---|
| 输出模式 | `output: "export"`，无 Node 服务端运行时 |
| 每页生成 | 构建时预渲染为 HTML（`sitemap.ts` / `robots.ts` / `llms.txt` 均标 `export const dynamic = "force-static"`） |
| 动态路由 | 全部用 `generateStaticParams()` 在构建时枚举具体参数 |
| 客户端组件 | 仅交互件（Header、微信弹窗、筛选等）标 `"use client"` |
| 图片优化 | `images.unoptimized: true`（静态站无图片优化服务），运行时不产生 `_next/image` 请求 |
| 上线形态 | 静态目录交给 Nginx（CVM）或 COS+CDN 托管 |

## 五、组件架构模式（三种）

| 模式 | 适用页面 | 做法 |
|---|---|---|
| **① 静态页直写 JSX** | 首页、品牌页、联系页、产品大类页 | 在 `page.tsx` 里直接组合组件，文案/数据从 `src/lib/*.ts` 引入 |
| **② 数据驱动渲染（车型/品牌页）** | 19 个车型页 | 页面只调用 `<VehiclePageRenderer config={...} />`；内容来自 `src/lib/<brand>-<model>-page-config.ts`（19 个），底层数据来自 `<brand>-products.ts` / `<brand>-upgrade-projects.ts` |
| **③ 内容驱动（博客）** | `/blog/*` | 读取 `src/content/articles/*.md`，frontmatter 解析 + markdown-it 渲染正文 |

`VehiclePageRenderer`（`src/components/vehicle-page/VehiclePageRenderer.tsx`）按固定顺序渲染：

```
Breadcrumbs → VehicleHero → ProjectTabs → ScenarioMatrix → ServiceFlow → FaqSection → BundleList(可选)
```

## 七、质量门禁（实际读取自 `package.json` 的 `scripts`）

| 命令 | 实际执行内容 |
|---|---|
| `npm run dev` | `next dev` 本地开发 |
| `npm run build` / `build:static` | `next build`（生成 `out/`） |
| `npm start` | `npx serve out` 本地预览静态产物 |
| `npm run lint` | `eslint` |
| `npm run typecheck` | `tsc --noEmit` |
| `npm test` | `vitest run` |
| `npm run test:e2e` | `playwright test` |
| `verify:zeekr-images` | `node scripts/verify-zeekr-images.mjs` |
| `verify:static-images` | `node scripts/verify-static-images.mjs` |
| `check:static-boundary` | `node scripts/check-static-export-boundary.mjs`（扫描 `src/app/api/`、`src/app/admin/`、prisma/auth 等运行时代码，确保可纯静态导出） |
| `check:static-output` | `node scripts/check-static-output.mjs`（校验 `out/` 完整、无 `/api/`、`localhost:3000`、`_next/image` 引用） |
| **`npm run check`** | `lint && typecheck && test && verify:zeekr-images && build` —— 日常提交前的统一门禁 |
| **`npm run check:static`** | 在 `check` 基础上追加 `verify:static-images && check:static-boundary && build && check:static-output` —— 静态站发布的完整门禁 |

## 八、一句话总结

这是一个「**Next.js App Router + 全静态导出 + 数据驱动页面**」的内容站：**改文案/数据 = 改 `src/lib` 或 `src/content` 的源文件 → 跑 `npm run check` → 重新构建 `out/` → 发布**，没有任何服务端逻辑。
