换轮毂不是看样式下单。销售给车主推荐之前要问诊，车主自己也可以先把六个问题想清楚：什么车型、原厂多少寸、为什么想换、想要什么效果、日常怎么用车、担心什么。带着答案到店，师傅帮你对参数，少花冤枉钱。

## 换轮毂前要先回答哪六个问题？

这六问来自门店问诊流程，顺序不用变，先答车型，再答需求。

| 序号 | 自查问题 | 要答出什么 |
| --- | --- | --- |
| 1 | 什么车型？ | 品牌 / 车型 / 具体版本 / 年份款型 |
| 2 | 原厂多少寸？ | 查车型手册，核对车辆 Tire and Loading Information 标签，必要时核实实车 |
| 3 | 为什么想换？ | 外观 / 轮胎 / 刹车 / 重量 |
| 4 | 想要什么效果？ | 原厂升级感 / 运动 / 商务 / 豪华 / 低趴 / 饱满 / 齐边 |
| 5 | 日常怎么用车？ | 城市 / 高速 / 长途 / 家庭满载 / 商务接待 |
| 6 | 担心什么？ | 续航 / 安全 / 蹭轮眉 / 年检合规 / 轮胎成本 / 舒适 / 售后 |

第二问提醒一下：原厂尺寸不要凭记忆答，车型手册和车门框上的 Tire and Loading Information 标签都是直接依据。第六问里的年检合规，口径以当地主管部门与保险公司为准，这篇不展开。

## 客户说的话，背后通常是什么需求？

门店里车主开口，说的往往不是需求本身，要先翻译一遍。下面这张表是常见的客户原话和真实需求对照。

| 客户原话 | 真实需求 |
| --- | --- |
| "原厂不好看" | 外观 |
| "我想做六活塞" | 制动升级空间适配 |
| "轮毂缩在里面不好看" | 视觉齐边和姿态 |
| "不想影响续航" | 对车辆效率变化敏感 |
| "一家六口经常跑长途" | 安全和实际载荷适配 |
| "我要轻的" | 需求还不明确，需要再追问：看重性能、受短视频影响、朋友推荐，还是觉得轻=高级 |

拿"我要轻的"举例：轻可能对应性能取向，也可能只是觉得轻显得高级，背后要配的方案不一样。先听懂话，再谈轮子。

## 为什么要先问清楚再推荐？

装得上，不等于适配。轮毂要跟轮端、安装孔、螺栓、制动系统、轮胎、悬架空间、车身轮拱一一对齐，单看一个参数定不了方案。

也不要用单一参数直接承诺整车效果。轮径、轮胎宽度、整套重量、空气动力、滚动阻力一变，加速感受、能耗、转向感受可能发生变化，注意是"可能"，不是一定。换轮毂之前，先想清楚自己为什么换，比先看样式重要。

## 带着答案到店，接下来怎么对参数？

六个问题的答案写清楚再到店，师傅会结合车型、轴荷和实际使用场景判断整套轮毂轮胎的适配，而不是凭一只轮毂的静态承重下结论。参数对不上的地方，门店会直接说明，不会硬推。
