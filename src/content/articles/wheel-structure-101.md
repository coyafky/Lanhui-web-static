拿到一只轮毂，J 值、ET、PCD 一串英文参数先把人绕住。其实参数不是凭空冒出来的，每个参数都对应轮毂上一个具体结构。这篇把 12 个结构逐个认全，再讲正面、侧面、背面按什么顺序看。

## 正面看得到哪些结构？背面又藏着哪些？

正面看得到：轮辋、轮缘、轮辐、中心区域、中心孔、安装孔、气门嘴孔。翻到背面才能看到：安装面、轮辋内桶、胎圈座、轮辋槽、凸峰结构、内部轮廓。

> 正面只能判断好不好看，不能完整判断适配。

很多真正影响安装的问题发生在轮毂里面，只看正面挑样式，参数对不上照样装不上。

## 12 个结构分别是什么、干什么用？

| 结构 | 位置与作用 |
| --- | --- |
| 轮辋 | 轮胎安装的环形主体，20 是名义直径、9 是名义宽度 |
| 轮缘 | 两侧凸起边缘，胎圈接触面，蹭马路牙子先伤这里 |
| 胎圈座 | 胎圈正确坐落的区域，没就位可能漏气、振动 |
| 轮辋槽 | 中间较深一圈，制造拆装空间，不靠蛮力 |
| 凸峰 | 胎圈座附近凸起，挡住胎圈向槽方向移动 |
| 轮辐 | 连接轮辋和中心区域，传力，不是装饰 |
| 中心区域 | 轮辐汇聚、与轮端安装关系密切的区域 |
| 中心孔 | 中央大孔，配合轮端做中心定位 |
| 安装孔 | 螺栓或螺柱+螺母对应的紧固孔 |
| 安装面 | 与轮端贴合的基准表面，ET 从这里理解 |
| 内桶 | 筒状空间，管轮胎安装和制动空间 |
| 轮辐背面 | 背面轮廓，卡钳避让的空间因素 |
| 气门嘴孔 | 装气门嘴；新能源还要确认 TPMS 兼容 |

**轮辋和轮胎怎么配合？** 乘用车普遍使用无内胎轮胎，直径 + 宽度匹配是基础要求。同样 20 寸 ≠ 所有 20 寸轮胎都适合，还要看轮辋宽度和制造商允许的适配范围。

**安装孔和 PCD 是什么关系？**

> 五孔一样 ≠ 能装（还要看 PCD）。

还要看这些孔围成的圆有多大——这就是 PCD。5×112 / 5×114.3 / 5×120 都是五孔，但 PCD 不同，孔数相同不等于能装。

**中心孔大了怎么办？** 太小可能根本无法正确安装到位；太大不一定不能装，但要按正确中心定位和安装方案处理，部分方案可用匹配的中心定位环。

**安装面和 ET 怎么联系？** ET 描述的就是安装面相对于轮辋中心线的位置关系。安装前要检查、清洁、定位、紧固、复核，污物、锈蚀、异物会影响贴合。

**卡钳避让看哪里？** 卡钳就在轮毂里面，间隙不够就干涉。大凹面不一定是为了避大卡钳，凸面也不一定不避卡钳，参数和实际轮廓一起看。

## 看一只轮毂按什么顺序看？

| 步骤 | 看什么 | 关注点 |
| --- | --- | --- |
| 正面 | 轮辐造型、中心区域、安装孔、中心孔、轮缘外观 | 好不好看、风格、孔数 |
| 侧面 | 宽度感、轮辐凸凹、轮缘状态、整体深度 | 深凹还是较平，不能仅靠肉眼判断 ET |
| 背面 | 安装面、中心孔、安装孔结构、轮辐背面、内桶、产品标识 | 适配、规格、产品识别 |

正面看风格，侧面看深度，背面才看适配，三步走完再下判断。

## 五大参数分别对应哪个结构？

五大参数不是突然冒出来的，它们全部来自轮毂本体结构：

| 参数 | 对应结构 |
| --- | --- |
| 直径 | 轮辋多大 |
| J 值/宽度 | 轮辋多宽 |
| PCD | 安装孔怎么分布 |
| CB 中心孔 | 中心孔多大 |
| ET | 安装面相对于轮辋中心线 |

## 哪些常见说法是错的？

| 错误说法 | 问题 |
| --- | --- |
| 整个金属轮毂都叫轮辋 | 轮辋只是环形安装部分 |
| 同样 20 寸原厂胎一定能装 | 还要看轮辋宽度与轮胎规格适配 |
| 五孔轮毂都一样 | 还要看 PCD，孔数相同不等于孔距相同 |
| 中心孔大一点拧紧螺丝就行 | 要按正确中心定位和安装方案处理 |
| 22 寸轮毂什么大卡钳都能装 | 还要看内桶、背面轮廓和制动空间 |
| 辐条越多越结实 | 不能直接判断，要看材料、设计、制造和测试 |
| 轮缘刮花只是不好看 | 要区分擦伤、变形、开裂、胎圈座损伤 |
| 卡钳避让只看轮毂尺寸 | 还要看内部空间，外径大 ≠ 卡钳一定能放下 |
